## Goal

A callout: a rounded, tinted box with an icon and rich text, to make a line stand out. Five tones, each with its own
colours in light and dark mode: Info (blue), Success (green), Warning (amber), Error (red) and Note (grey).
Moved into Phase 0 by the owner (2026-10-31); the spec listed callouts under Phase 2.

## Notes

Owner's choices (2026-10-31): five tones, a fixed icon per tone (no custom emoji), text only (no blocks nested
inside, like a quote). The page stores the kind `callout` and its tone by name; a tone this version doesn't know is
kept and drawn grey (rule 5). Markdown uses GitHub's alert syntax (`> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`,
`> [!CAUTION]`) so callouts survive copy and paste to other apps.
