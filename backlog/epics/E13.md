## Goal

Phase 2. Open a Leaf workspace in any web browser, read-only: the page tree, every page with its formatting and
images, and links you can share to a single page. The desktop app exports a self-contained folder (a "web bundle")
that can be put on any static host. No server, no accounts, no editing, no sync.

## Notes

Why first: it proves the core crates (`leaf-model`, `leaf-editor`) run in a real browser through WebAssembly and
builds the web rendering layer the Phase 3 web editor (E14) reuses, without needing sync or a server. Chosen over a
mobile app first (owner, 2026-10-29).

Order: S01 spike + ADR → S02 bundle format and S03 page rendering (in parallel) → S04 navigation, S05 images →
S06 export from the desktop app → S07 CI and browser smoke test. S08 (search) is optional.

Rules that still apply: the viewer never changes documents; unknown data in a bundle is kept, not dropped (rule 5);
the desktop export writes files only, with no network access.
