## Goal

A plain grid of text cells inside a page, like Notion's "simple table": paste a markdown table and get a table,
type in cells, add and remove rows and columns, copy it back out as markdown. Added to Phase 0 by the owner
(2026-10-30) after pasted markdown tables came in as loose text.

## Notes

This is not a database (E09, Phase 1): cells hold rich text only, with no column types, sorting or filtering, and
rows are not pages. One ADR (in E16-S01) records the model shape and how it stays apart from databases.
