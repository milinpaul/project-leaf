## Context

The 10,000-case undo property test on `main` (E02-S08) fails on all three OSes. `RemoveMark` on text that doesn't
carry the mark (and `SetMark` on text that already carries it) still writes a Loro op, so it reports `Changed`, but
Loro records no undo step for it. The editor would then expect an undo that never comes. Shrunk case: insert
"leaf", italic 0..2, remove italic 2..3.

## Acceptance criteria

- [x] Failing regression test first
- [x] `RemoveMark` where the range has no such mark → `Unchanged`, no commit
- [x] `SetMark` where the whole range already has that exact mark → `Unchanged`, no commit
- [x] Undo property test passes at `PROPTEST_CASES=10000`
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **`text_ops.rs`:** before writing, read the mark's value on each run of text in the range (`slice_delta`).
  - **`SetMark`:** `Unchanged` when every run already has that exact value. A different link target is still a
    change.
  - **`RemoveMark`:** `Unchanged` when no run has the mark.
- **Regression test:** the shrunk case plus partial and different-value cases. Then run the property tests at
  10,000 cases locally.
