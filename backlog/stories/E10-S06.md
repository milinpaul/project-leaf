## Context

Find which pages link to a page fast (ADR-071): a `links` table in the disposable search index, filled while a
page's text is indexed and rebuilt with it.

## Acceptance criteria

- [ ] `links(source_page, source_block, target_page)` table indexed by target; `INDEX_VERSION` raised so existing indexes rebuild once
- [ ] Indexing a page replaces its links in the same transaction as its text; removing a page removes its links
- [ ] `backlinks(page)` returns each linking page and block with a short excerpt around the link, pages in the trash left out, one entry per block
- [ ] Benchmark in leaf-bench: backlinks lookup on the 5,000-page fixture with 25,000 links under 5 ms p95
- [ ] Tests added; coverage gate holds; `just check` passes
