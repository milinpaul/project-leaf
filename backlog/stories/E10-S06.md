## Context

Find which pages link to a page fast (ADR-071): a `links` table in the disposable search index, filled while a
page's text is indexed and rebuilt with it.

## Acceptance criteria

- [x] `links(source_page, source_block, target_page)` table indexed by target; `INDEX_VERSION` raised so existing indexes rebuild once
- [x] Indexing a page replaces its links in the same transaction as its text; removing a page removes its links
- [x] `backlinks(page)` returns each linking page and block with a short excerpt around the link, pages in the trash left out, one entry per block
- [x] Benchmark in leaf-bench: backlinks lookup on the 5,000-page fixture with 25,000 links under 5 ms p95
- [x] Tests added; coverage gate holds; `just check` passes

## Plan

- `links` table in the search index (version 4), filled in `index_page`'s transaction from `PageText::links`
  (`page_text` reads each block's links with the words around them); cleared with the page and with `clear`.
- `backlinks(page)` on `Searcher` and `SearchIndex`: pages by title, blocks in reading order, no self-links.
- `leaf_fixtures::add_links` and a backlinks budget in `just bench-search`.
- Tests: listing, order, one entry per block, excerpts and cuts, edits, trash, restore, clear.
