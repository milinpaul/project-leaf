## Context

Restore cursor/selection on undo and redo.

## Acceptance criteria

- [x] Undo restores exact selection
- [x] Redo restores post-edit selection
- [x] Tests across structural and text edits
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-model`: `SavedSelection { caret, tail, blocks }`; each undo step stores a step number, and `PageDoc` keeps
  a table of before/after selections (Loro pops before pushing the inverse, so the number survives undo/redo).
  `set_selection` (before), `record_after` (after; ignored if the page didn't change). `History::Done { selection }`.
- `leaf-editor`: `begin`/`finish` around every editing action; `PageEditor::undo`/`redo` restore caret, tail and
  selected blocks.
- Tests: model undo tests (cycles, merged typing, no-op actions) and `history/tests.rs` across typing, cross-block
  typing, Enter/Backspace/Tab, block deletion, formatting and multi-step sequences. ADR-023.
