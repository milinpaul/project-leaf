## Context

Draw the table view in `leaf-ui`: header with column names and type icons, rows virtualised like the page list, a new-row line at the bottom, horizontal scrolling for wide tables. Cells edit in place by type: text and URL inline, number, checkbox toggle, select and multi-select pickers with option create/rename/colour, date picker.

## Acceptance criteria

- [x] Full-page database draws its columns and rows from the view model
- [x] Each property type edits in place with the keyboard and the mouse
- [x] New row at the bottom; Enter/Tab/arrows move between cells
- [x] Verified with screenshots in light and dark
- [x] Tests added; `just check` passes

## Plan

- `leaf-editor` `database_view/edit.rs`: which editor each cell opens and what each input writes (`CellEditor`,
  `commit_text`, `toggle_checkbox`, `option_picker`, `toggle_option`, `create_option`, `set_date`), unit-tested.
- `WorkspaceEditor::database_view` / `read_database`; a new database starts with a "Tags" column.
