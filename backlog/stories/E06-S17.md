## Context

The owner wants a search field at the top of the sidebar, like Notion's: a rounded box under the workspace header
reading "Search" with the shortcut shown at its right (`⌘K` on macOS, `Ctrl+K` elsewhere). It is a doorway, not a
second search: clicking it opens the existing search bar (E11), exactly as the shortcut does. No "ask" (no AI or
network in Phase 0).

## Acceptance criteria

- [ ] A full-width, rounded search field under the sidebar header with a search icon, "Search" placeholder and the platform's shortcut hint at the right, in Leaf's theme (light and dark)
- [ ] Clicking it (or pressing Enter/Space when focused) opens the search bar, the same as `Cmd/Ctrl+K`; it never holds text itself
- [ ] Hover and focus states; tooltip-free (the hint says it all); reachable by keyboard
- [ ] Hidden with the rest of the sidebar when the sidebar is collapsed
- [ ] Window test that a click opens the search bar; screenshots in the PR, light and dark
- [ ] Tests added; `just check` passes; docs updated if structure changed
