## Context

The first version of the Leaf web app (ADR-XXX-E14-S02): a Next.js app that opens a workspace stored in the browser,
lists its pages and edits one, through `leaf-web` (E14-S03). Enough to type a real page and find it again after a
reload; the rest of the browser layer (selection by mouse, input methods, menus, images, search) follows in its own
stories.

## Acceptance criteria

- [ ] A Next.js app in `web/` (TypeScript, App Router) with Leaf's look from the shared theme tokens (paper colours,
      Inter and the code font, light and dark following the browser)
- [ ] First visit creates a workspace in the browser; the sidebar lists its pages from `leaf-web`; "New page" adds one
- [ ] A page opens in the editor: title and blocks drawn from the view rows, a hidden text input for typing, Enter,
      Backspace, Tab, arrows, undo and redo, bold and italic, Markdown shortcuts
- [ ] Every change is saved to IndexedDB as Loro updates; a reload brings the workspace and pages back exactly
- [ ] Playwright tests in CI: create a page, type, reload, find it; screenshots in light and dark
- [ ] README for running it locally (`npm run dev`); `just check` passes and the web app's own lint and tests pass
