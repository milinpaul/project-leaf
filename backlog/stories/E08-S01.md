## Context

Generator for big pages and deep page trees.

## Acceptance criteria

- [x] 10k-block page and 5k-page workspace fixtures
- [x] Deterministic with a seed
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- New crate `leaf-fixtures` (test support; depends on `leaf-core`, `leaf-model`, `leaf-store`): `big_page(seed, n)`,
  `page_tree(seed, n)`, `big_workspace(seed, pages, blocks_per_page)`, `save_to_folder`, built through real model
  commands. Own SplitMix64 generator (no dependency); a seed fixes the outline (IDs are minted by the model).
- Sizes as constants: 10,000-block page, 5,000-page workspace, 20 blocks per page (100,000 blocks for E11-S07).
- `just fixture <folder> [seed]` writes the full-size workspace for manual testing.
- Tests: same seed same outline (page and workspace), different seed different; every block kind, nesting and
  formatting present; full sizes; save to a folder and load back. Architecture test covers the new crate.
- Docs: ADR, ARCHITECTURE and TECH_STACK crate lists.
