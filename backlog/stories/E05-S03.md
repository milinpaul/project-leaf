## Context

Turn into, duplicate, delete from the block handle menu.

## Acceptance criteria

- [x] Actions work on single and multi-block selection
- [x] Duplicate deep-copies subtree with new ids
- [x] Each action is one undo step
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-model`: new `DuplicateBlocks { ids }` command (`page_doc/duplicate.rs`): deep copy of each outermost block
  right after it, every stored entry copied (unknown props, marks, nested maps/lists/texts), new IDs; added to the
  invariants proptest.
- `leaf-editor/src/block_actions.rs`: `action_targets(block)` (the selection if the block is part of it, else the
  block), `block_action(block, TurnInto | Duplicate | Delete)`, one undo step each; copies end up selected.
- Tests: model duplicate tests and `block_actions/tests.rs`; ADR 0028.
