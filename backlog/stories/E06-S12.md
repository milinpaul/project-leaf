## Context

Design and add the first five built-in covers, one per category. They are drawn by Leaf (gradients and abstract
shapes), not photos: tiny, sharp at any size, no licensing. The owner approves previews before they ship.

| Name | Category | Feel |
|---|---|---|
| Dawn | Writing / journal | Warm peach-to-rose gradient |
| Forest | Personal / nature / travel | Deep green layered hills |
| Ocean | Work / projects | Calm blue waves |
| Paper | Notes / research | Soft off-white with a subtle texture |
| Night | Ideas / creative | Indigo-to-violet with a faint glow |

## Acceptance criteria

- [ ] Previews of all five shown to the owner (screenshots in the PR) and approved before merge; names or colours adjusted as asked
- [ ] Each looks good in light and dark mode and at narrow and very wide window sizes
- [ ] All five appear in the cover picker under stable names (`builtin:dawn`, `builtin:forest`, `builtin:ocean`, `builtin:paper`, `builtin:night`); names never change once shipped
- [ ] No large image files: covers are code or small vector files; app size impact noted in the PR
- [ ] Tests added; `just check` passes; docs updated if structure changed
