## Context

Design and add the first six built-in covers, one per category (Travel added at the owner's request, 2026-10-29). They are drawn by Leaf (gradients and abstract
shapes), not photos: tiny, sharp at any size, no licensing. The owner approves previews before they ship.

| Name | Category | Feel |
|---|---|---|
| Dawn | Writing / journal | Warm peach-to-rose gradient |
| Forest | Personal / nature | Misty layers of pine trees |
| Ocean | Work / projects | Calm water from above, with ripple rings |
| Paper | Notes / research | Soft off-white with a subtle texture |
| Night | Ideas / creative | Indigo-to-violet with stars and a crescent moon |
| Travel | Trips / travel plans | A map: contour lines, a dashed flight route with a paper plane, pins, a compass |

## Acceptance criteria

- [x] Previews of all six shown to the owner (screenshots in the PR) and approved before merge; names or colours adjusted as asked
- [x] Each looks good in light and dark mode and at narrow and very wide window sizes
- [x] All six appear in the cover picker under stable names (`builtin:dawn`, `builtin:forest`, `builtin:ocean`, `builtin:paper`, `builtin:night`, `builtin:travel`); names never change once shipped
- [x] No large image files: covers are code or small vector files; app size impact noted in the PR
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Covers are SVG files (1200×300) in `crates/leaf-ui/assets/covers/`, generated once by a small script (not kept)
  and checked in a contact sheet, then in the real app.
- Each cover uses a different composition so they don't read alike (owner feedback: Forest and Ocean first looked
  the same): Dawn soft hills and sun, Forest a pine treeline, Ocean ripples seen from above, Paper a texture, Night a
  starry sky, Travel a map.
- Key elements stay in a central safe area, because the band crops the picture to fit (`ObjectFit::Cover`).
- The band's height now follows its width (3.5:1, 160–320 px) via an invisible spacer, so very wide windows don't
  crop most of the picture away and narrow ones keep the middle. ADR 0045 updated.
- `BuiltinCover` gains Forest, Ocean, Paper, Night, Travel; `leaf_ui::covers` maps each to its file.
