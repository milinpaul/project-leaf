## Context

A thin bar above the open page. Left: the breadcrumb, meaning the parent pages, then the page's own icon and title,
each clickable, with long paths shortened in the middle (`Home / … / Parent / Page`). Right: "Edited 3 minutes
ago", the star, and the `⋯` button. The view model lives in `leaf-editor`; the UI only draws it.

## Acceptance criteria

- [ ] Breadcrumb view model in `leaf-editor`: ancestors and the page, with icons and "Untitled" for empty titles; shortened to the first, an ellipsis and the last two when long; tested
- [ ] Clicking a breadcrumb opens that page; the title follows renames and icon changes at once
- [ ] The edited label updates while the page stays open (at least once a minute, and straight after an edit) and shows the full date and time on hover
- [ ] The star is filled when the page is a favourite; clicking it toggles that (E17-S02)
- [ ] The `⋯` button is there and opens the page menu (its items come in E17-S04)
- [ ] Stays one line at narrow window widths (title truncates first); light and dark themes; screenshots in the PR
- [ ] Tests added; `just check` passes; docs updated if structure changed
