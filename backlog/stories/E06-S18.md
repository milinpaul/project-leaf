## Context

The sidebar can already be hidden with `Cmd/Ctrl+\` or View → Toggle Sidebar, and Leaf remembers it. But there is
no button for it, and once hidden nothing on screen brings it back. The owner wants Notion's pattern: a
sidebar-shaped collapse button at the top of the sidebar, and, while the sidebar is collapsed, a menu (☰) button at
the top left of the page that reopens it. When the page top bar arrives (E18-S03, Phase 1), the ☰ button moves into
its left end.

## Acceptance criteria

- [x] A collapse button (sidebar icon) at the top of the sidebar header, with a tooltip naming the shortcut; clicking it hides the sidebar, like `Cmd/Ctrl+\`
- [x] While the sidebar is hidden, a ☰ button at the top left of the page area reopens it; it doesn't cover the page's title or icon (it floats in the corner, so the page doesn't jump; over a cover it has a soft backing), and the window keeps its normal title bar
- [x] The hidden state is still saved and restored on the next launch (as today); the shortcut and the menu item keep working
- [x] Keyboard focus goes somewhere sensible after each toggle (the page stays focused)
- [x] Window tests for both buttons; screenshots in the PR of both states, light and dark
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- New `leaf-ui/src/shell/sidebar_toggle.rs`: `Shell::toggle_sidebar(refocus)` (the shortcut and both buttons
  use it), the collapse button (panel-left icon, tooltip with the shortcut) placed in the sidebar header before
  the compose button, and the ☰ reopen button.
- The ☰ button floats in the page's top-left corner rather than taking a row: a row pushed the page down 48 px
  each time the sidebar hid. A soft backing keeps it readable over a cover.
- Focus: after a button click, the open page gets the keyboard back; the shortcut leaves focus where it is (so
  toggling while editing the title keeps the title focused).
- Icons `Menu` and `PanelLeft` added to Leaf's bundle. Screenshot tool: `nosidebar` option.
- Window test: both buttons toggle, the state is the saved setting, the page keeps focus, the search field hides
  with the sidebar. Docs: ARCHITECTURE window paragraph.
