## Context

The sidebar can already be hidden with `Cmd/Ctrl+\` or View → Toggle Sidebar, and Leaf remembers it. But there is
no button for it, and once hidden nothing on screen brings it back. The owner wants Notion's pattern: a
sidebar-shaped collapse button at the top of the sidebar, and, while the sidebar is collapsed, a menu (☰) button at
the top left of the page that reopens it. When the page top bar arrives (E17-S03, Phase 1), the ☰ button moves into
its left end.

## Acceptance criteria

- [ ] A collapse button (sidebar icon) at the top of the sidebar header, with a tooltip naming the shortcut; clicking it hides the sidebar, like `Cmd/Ctrl+\`
- [ ] While the sidebar is hidden, a ☰ button at the top left of the page area reopens it; it doesn't cover the page's title, icon or cover, and leaves room for the macOS window buttons
- [ ] The hidden state is still saved and restored on the next launch (as today); the shortcut and the menu item keep working
- [ ] Keyboard focus goes somewhere sensible after each toggle (the page stays focused)
- [ ] Window tests for both buttons; screenshots in the PR of both states, light and dark
- [ ] Tests added; `just check` passes; docs updated if structure changed
