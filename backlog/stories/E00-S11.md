## Context

The repository is public and the owner now welcomes issues and pull requests from outside contributors
(2026-10-31). There is no README, no licence file (Cargo.toml already says `MIT OR Apache-2.0`) and no guide for
contributors. A visitor should understand what Leaf is, see it, build and install it, and know how to help.

## Acceptance criteria

- [x] `README.md`: what Leaf is, screenshots, status, install and build steps for macOS, Linux and Windows, project layout, links to the docs
- [x] `CONTRIBUTING.md`: dev setup, `just` tasks, the rules a PR must meet, how issues and the backlog fit together
- [x] `LICENSE-MIT` and `LICENSE-APACHE` matching the licence already declared in `Cargo.toml`
- [x] Issue templates (bug, feature), a pull request template, `CODE_OF_CONDUCT.md` and `SECURITY.md`
- [x] `just check` passes (docs only: `typos` and the backlog check run locally, CI runs the rest)

## Plan

Docs only, no code. Write the README from PRODUCT_SPEC.md (vision, Phase 0 features, roadmap), TECH_STACK.md and
the `justfile` (`setup`, `run`, `install`). Screenshots reuse existing `docs/screenshots/` images. CONTRIBUTING
condenses CLAUDE.md's rules for human contributors. Licence texts are copied from the Rust toolchain's bundled
copies. Templates live in `.github/`.
