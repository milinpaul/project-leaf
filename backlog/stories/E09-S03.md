## Context

`DocKey::Database` in `leaf-store`, autosave and crash recovery like pages. A full-page database is a page whose content is a database. Each row is a page in the workspace document, marked as a row of its database, created together with the row (one undo step across both documents, the rule decided in ADR 0066).

## Acceptance criteria

- [ ] Databases save, load and recover like pages
- [ ] Adding a row creates its page; deleting a row trashes it; restoring brings the row back in place
- [ ] Row pages are left out of the sidebar, or shown under the database (owner's answer to ADR 0066 question 1)
- [ ] Tests added; `just check` passes; docs updated
