## Plan

- **`page_doc/invariants.rs`:** `PageDoc::check_invariants() -> Result<(), Vec<InvariantViolation>>`. It reads the
  raw Loro tree, not the index or read API, so it would catch bugs those layers hide. Checks:
  - 1 every node has a text `type`;
  - 2 a `text` container exactly for text-bearing kinds;
  - 3 no children under kinds that disallow them;
  - 4 heading level 1–3 (and every known kind's props readable);
  - 5 code text carries no marks;
  - 6 no cycles: each node's parent chain reaches the root;
  - 8 every node has a valid, unique `id`, matching the index.

  Unknown kinds (from newer versions) are exempt from 2 and 3, because their rules are unknown.
- **Invariant 7** is about history, not state: it needs page undo (E02-S08), whose criteria already include the
  undo round-trip test. E02-S08 gets a note to assert it.
- **`tests/page_invariants.rs`:** a proptest strategy that picks **every** page command with real block ids from the
  page: insert (all kinds), delete, move, indent, outdent, text insert/delete, set/remove mark, set kind, set prop,
  split, merge. After each step: `check_invariants()`. At the end, a reload must give the same outline.
- **10k cases:** measure in a debug build; if too slow for CI, run 10k on `main` (the test job) and fewer on PRs.
- **Proof:** plant real bugs (skip stripping marks on code, skip moving children out of a heading) and confirm
  the test finds them.
