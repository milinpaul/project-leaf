## Context

How action items behave while writing, in `leaf-editor` as plain Rust: making one, ticking it off, Enter and
Backspace, and the view model the UI draws (label for the date, overdue flag), with "today" passed in by the app.
Add the rules to PRODUCT_SPEC.md "Editor behaviour", each with a test.

## Acceptance criteria

- [ ] Slash menu "Action item" and "Turn into → Action item"; a Markdown shortcut (e.g. `[!] `) at the start of a block
- [ ] Enter at the end of an action item starts a new one (no date, same priority); Enter on an empty one turns it into a paragraph; Backspace at its start turns it into a paragraph, keeping the text
- [ ] A keyboard shortcut ticks the caret's action item off and on (Cmd/Ctrl+Enter, as for to-dos if they have one)
- [ ] The row's view model has done, a short date label (Today, Tomorrow, Fri 31 Oct, 30 Oct 2027, plus the time), the priority, and overdue (due before today, or today at a time already passed, and not done); insta snapshots
- [ ] Undo restores every change; the rules are in PRODUCT_SPEC.md "Editor behaviour"
- [ ] Tests added; `just check` passes; docs updated if structure changed
