## Context

How action items behave while writing, in `leaf-editor` as plain Rust: making one, ticking it off, Enter and
Backspace, and the view model the UI draws (label for the date, overdue flag), with "today" passed in by the app.
Add the rules to PRODUCT_SPEC.md "Editor behaviour", each with a test.

## Acceptance criteria

- [x] Slash menu "Action item" and "Turn into → Action item"; a Markdown shortcut (e.g. `[!] `) at the start of a block
- [x] Enter at the end of an action item starts a new one (no date, same priority); Enter on an empty one turns it into a paragraph; Backspace at its start turns it into a paragraph, keeping the text
- [x] A keyboard shortcut ticks the caret's action item off and on (Cmd/Ctrl+Enter, as for to-dos if they have one)
- [x] The row's view model has done, a short date label (Today, Tomorrow, Fri 31 Oct, 30 Oct 2027, plus the time), the priority, and overdue (due before today, or today at a time already passed, and not done); insta snapshots
- [x] Undo restores every change; the rules are in PRODUCT_SPEC.md "Editor behaviour"
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Model (`split_merge.rs`): splitting a task makes a task, not done, no date, same priority.
- Editor: Enter on an empty task turns it into a paragraph (like list items, `enter_in`); slash item "Action item"
  (keywords task, action, due, deadline, `[!]`; "task" moves off the to-do); Turn into list; shortcut `[!] `.
- Cmd/Ctrl+Enter (`Key::ModEnter`, a no-op outside code today) ticks a task off and on; to-dos too, as in Notion.
- View: `BlockStyle::Task { done, due, time, priority }` (raw fields: rows are cached, so nothing in them may
  depend on the clock). `leaf_editor::task_due`: `due_label(due, time, today)` (Today, Tomorrow, Yesterday,
  "Fri 31 Oct", "Sat 30 Oct 2027", plus " 14:30") and `is_overdue(done, due, time, today, now)`, plain functions of
  the date and time the app passes, like `edited.rs`. Snapshots and unit tests.
- PRODUCT_SPEC "Editor behaviour" rows, each with a test.
