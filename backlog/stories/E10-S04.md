## Context

Draw a page link as the target's icon and title, and open the page on click (ADR 0071). Unlike web links, a plain
click opens it: it never leaves the app.

## Acceptance criteria

- [ ] A link draws as icon + title, underlined, in the text's flow and wrapping like a word; it follows the theme in light and dark
- [ ] A plain click opens the target page; the caret can still be placed beside it with the keyboard
- [ ] In the trash: greyed title with "In trash"; deleted for good: greyed "Deleted page"; clicking a link to a page in the trash opens it with the trash banner, as today
- [ ] Renaming or re-iconing the target updates every visible link straight away
- [ ] Window tests for click and redraw; screenshots light and dark; `just check` passes
