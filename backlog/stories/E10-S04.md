## Context

Draw a page link as the target's icon and title, and open the page on click (ADR 0071). Unlike web links, a plain
click opens it: it never leaves the app.

## Acceptance criteria

- [x] A link draws as icon + title, underlined, in the text's flow and wrapping like a word; it follows the theme in light and dark
- [x] A plain click opens the target page; the caret can still be placed beside it with the keyboard
- [x] In the trash: greyed title with "In trash"; deleted for good: greyed "Deleted page"; clicking a link to a page in the trash opens it with the trash banner, as today
- [x] Renaming or re-iconing the target updates every visible link straight away
- [x] Window tests for click and redraw; screenshots light and dark; `just check` passes

## Plan

With E10-S03. `render_rich_text` draws `LinkedText`'s runs; live links in the link colour, underlined; trashed and
deleted greyed. The painted layout keeps the position map (offsets, carets, Up/Down, `link_at` for clicks). A plain
click on a live or trashed link calls `Shell::open`. Window tests and screenshots from the demo workspace, which now
links to its own pages.
