## Context

`leaf-search` opens its own disposable index file, `search/index.sqlite`, with an FTS5 table (ADR 0019). It never
touches `workspace.sqlite`.

## Acceptance criteria

- [x] Test proves FTS5 and the `unicode61 remove_diacritics` tokenizer work in our bundled SQLite on all three OSes
- [x] `SearchIndex::open(workspace_root)` creates `search/index.sqlite` with an FTS5 table (page, block, kind, text) and a title table
- [x] Index stores an index version; a missing, damaged or older-version file is deleted and recreated empty, and the caller is told a rebuild is needed
- [x] `index_page`, `remove_page` and `clear` write in one transaction each
- [x] `rusqlite` added to `leaf-search`; architecture test still passes; crate `//!` doc updated
- [x] Tests added; `just check` passes; coverage ≥ 90%

## Plan

- **Branch:** `story/E11-S01`, stacked on `docs/phase0-search` (PR #34), which adds this story and ADR 0019.
- **Files:** `crates/leaf-search/` gets `error.rs` (`SearchError`), `page_text.rs` (input rows: `PageText`,
  `BlockText`, plain data so S02 fills them from the model), `schema.rs` (SQL + `INDEX_VERSION`), `index.rs`
  (`SearchIndex`). Deps: `leaf-core`, `rusqlite`, `thiserror`, `tracing` (all already in the workspace).
- **Schema:** `meta(key, value)`; FTS5 tables `blocks(page_id, block_id, kind UNINDEXED…, text)` and
  `titles(page_id, title)`, tokenizer `unicode61 remove_diacritics 2`, prefix indexes for type-ahead.
- **Open:** `SearchIndex::open(workspace_root)` → `(index, IndexState)`. `NeedsRebuild` when the file is new,
  was recreated (unreadable/damaged, other version), or the last rebuild never finished (a `complete` flag
  set by `mark_complete`, cleared by `clear`). Recreate = delete the file plus `-wal`/`-shm`, start empty.
- **Writes:** `index_page` replaces a page's rows, `remove_page`, `clear`; one transaction each.
- **Tests:** integration tests with a temp workspace folder: FTS5 + diacritics + prefix work, open states,
  garbage/other-version files recreated, writes replace rows, transactions. Coverage ≥ 90%.
- **Risk:** FTS5 must be in the bundled SQLite; the first test proves it (CI runs it on all three OSes).
