## Context

Leaf shows a generic icon in the Dock, taskbar and app switcher. Give it its own modern icon, drawn once as an
SVG and generated into every format each OS needs, and make the app show it when it runs. Installers are
E08-S04; this story only adds the artwork and the per-OS wiring they will reuse.

## Acceptance criteria

- [x] One master SVG; PNG sizes, macOS `.icns` and Windows `.ico` generated from it by one command
- [x] macOS: `just run` launches Leaf from a `Leaf.app` bundle, so the Dock and app switcher show the icon
- [ ] Windows: the icon is built into `leaf.exe`
- [ ] Linux: the window gets the icon (X11) and a `.desktop` entry ships alongside the PNG files
- [x] Verified with screenshots on macOS
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Draw `crates/leaf-app/resources/icon.svg` (macOS grid: 824 px tile on 1024 canvas). `scripts/icons.py` (`just icons`)
  renders PNG files with `resvg`, `Leaf.icns` with `iconutil`, writes `leaf.ico` directly. Outputs are committed.
- macOS: `scripts/macos_app.py` wraps the binary in `Leaf.app` (Info.plist + icns); `just run` launches from it.
- Windows: `build.rs` + `leaf.rc` embed icon resource 1 via `embed-resource` (GPUI loads id 1).
- Linux: `app_id` + X11 window icon (`image`, PNG only); `.desktop` entry named after the app ID.
- Tests: `leaf-app/tests/icon.rs` checks sizes, ICO/ICNS structure and that the app ID matches everywhere.
- Risk: Windows/Linux can't be run here; run the full CI matrix on the branch.
