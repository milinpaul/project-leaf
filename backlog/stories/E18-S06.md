## Context

Like Notion, the `⋯` menu gets a "Full width" switch. On, the page itself (its title and every block) uses the page
area's whole width, keeping the side margins, instead of the reading column; off, it goes back. The cover is not
affected: it already spans the page area. It is a setting of that page, saved in the workspace document, so it
survives restarts and will sync. Other pages keep
their own setting.

## Acceptance criteria

- [x] Model: each page has a full-width setting (off by default), changed by a command, undoable, saved and reloaded; old pages without it read as off; a value from a newer version is kept, not dropped
- [x] The `⋯` menu shows "Full width" with a switch showing its state; choosing it flips the setting and the page relayouts at once
- [x] Full width: the title and blocks fill the page area minus its margins; off: the reading column as today; the cover is unchanged either way
- [x] The setting is per page: switching pages shows each page's own width
- [x] Screenshots in the PR, full width on and off
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-model`: `full_width` key in the page's meta (missing or null reads as off; on is stored as `true`, off
  deletes the key, like the cover); `PageMeta::full_width`; `WorkspaceCommand::SetPageFullWidth { page, full_width }`,
  one undo step, no-op when unchanged. Not an edit: it doesn't move the page's edited time. Tests in
  `workspace/apply/width_tests.rs` (set, clear, no-op, unknown page, undo, save and reload). BLOCK_MODEL.md keys.
- `leaf-editor`: `set_full_width` / `is_full_width`; `PageAction::ToggleFullWidth`, `PageMenuIcon::FullWidth`, and
  `PageMenuEntry::switch: Option<bool>` so the menu shows the state. Top bar only, after Rename, in its own group.
- `leaf-ui`: `column(content, full_width)` drops the reading-width cap when on (keeps the side margins); the shell
  reads the open page's setting for each row it lays out. The menu row draws a display-only `Switch`; the row click flips it.
  Window tests: toggling widens the title and blocks, per page, and survives a reload. Screenshot tool: `wide`
  option. ADR 0065 amended (menu entry + page setting).
