## Context

Cmd/Ctrl+P fuzzy page search by title. Build it so full-text search (E11-S05) can extend the same box,
which `Cmd/Ctrl+K` will also open (ADR 0019).

## Acceptance criteria

- [x] Fuzzy match with path breadcrumbs
- [x] Keyboard only usable
- [x] Opens in < 50 ms with 5k pages
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Matcher (`leaf-editor/src/fuzzy.rs`)**: case-insensitive; each word of the query must match the title (any
  order). Exact > prefix > word start > substring > letters in order (bonus for runs and word starts, penalty for
  gaps). Returns a score and the matched character ranges for highlighting. Accent folding comes with full-text
  search (E11-S05), which already ignores accents via FTS5.
- **Switcher (`leaf-editor/src/switcher.rs`)**: `QuickSwitcher::open(workspace, recent)` snapshots live pages with
  their breadcrumb (ancestor titles) in one tree walk; `set_query`, `move_selection` (wrapping), `chosen`. Empty query
  lists recently opened pages, then the rest in tree order. At most 50 results. `WorkspaceEditor` keeps the
  recently opened pages (in memory; E06-S08 persists them).
- **UI (`leaf-ui/src/shell/switcher.rs`)**: `QuickSwitch` action on Cmd/Ctrl+P (menu item under the app menu);
  a centred dialog with a search field and result rows (icon, title with matched letters in bold, breadcrumb).
  Up/Down/Enter/Escape; mouse click works too. The search bar (E11-S05/06) extends this box and adds Cmd/Ctrl+K.
- **Tests**: matcher ranking and highlights; switcher state, wrapping, recents, trashed pages left out; insta
  snapshot of results; 5,000-page open + query timing; GPUI test: Cmd+P, type, Enter opens the page.
