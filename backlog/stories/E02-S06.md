## Context

Tab and Shift+Tab structural moves.

## Acceptance criteria

- [x] Indent makes block the last child of previous sibling
- [x] Outdent moves block after its parent, following siblings become its children (Notion behaviour)
- [x] No-op cases return Ok without a commit
- [x] Works for multi-block selections
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `PageCommand::Indent { ids }` / `Outdent { ids }`, applied to the outermost listed blocks one by one in
  reading order (gives Notion's result for consecutive selections).
- Indent: block becomes the last child of its previous sibling. Skipped when there is no previous sibling or it
  can't hold children (heading, code, divider, image, unknown).
- Outdent: block moves right after its parent; its following siblings become its last children, in order.
  Skipped at the top level, or when the block can't hold children but has following siblings (moving them
  elsewhere would reorder the text).
- A command where every block is skipped writes nothing and returns `Unchanged`.
- Tests: each rule and skip; multi-block indent/outdent; no commit on no-ops. Extend the block-tree proptest
  reference model with indent/outdent.
