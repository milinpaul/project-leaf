## Context

Prove `leaf-model` and `leaf-editor` work in a real browser, and choose how the web UI is written (Rust with
Leptos/Dioxus, or TypeScript calling the Rust core through `wasm-bindgen`). The core crates already build for
`wasm32-unknown-unknown`; this checks they also load and run, and measures download size and load time.

## Acceptance criteria

- [ ] A throwaway page loads a page's Loro snapshot in the browser and lists its blocks from `PageView`
- [ ] Download size (compressed) and time to first render measured and written down
- [ ] ADR records the web UI choice, the new crate(s) and where they sit in the dependency rules
- [ ] `docs/architecture/ARCHITECTURE.md` and TECH_STACK.md updated with the web layer
- [ ] Tests added; `just check` passes; docs updated if structure changed
