## Context

A thin bar above the open page. Left: the breadcrumb, meaning the parent pages, then the page's own icon and title,
each clickable, with long paths shortened in the middle (`Home / … / Parent / Page`). Right: "Edited 3 minutes
ago", the star, and the `⋯` button. The view model lives in `leaf-editor`; the UI only draws it.

## Acceptance criteria

- [x] Breadcrumb view model in `leaf-editor`: ancestors and the page, with icons and "Untitled" for empty titles; shortened to the first, an ellipsis and the last two when long; tested
- [x] Clicking a breadcrumb opens that page; the title follows renames and icon changes at once
- [x] The edited label updates while the page stays open (at least once a minute, and straight after an edit) and shows the full date and time on hover
- [x] The star is filled when the page is a favourite; clicking it toggles that (E18-S02)
- [x] While the sidebar is collapsed, its ☰ reopen button (E06-S18) sits at the bar's left end, before the breadcrumb
- [x] The `⋯` button is there and opens the page menu (its items come in E18-S04)
- [x] Stays one line at narrow window widths (title truncates first); light and dark themes; screenshots in the PR
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor`: `WorkspaceEditor::breadcrumb(page) -> Vec<Crumb>` (`workspace_editor/breadcrumb.rs`): ancestors
  then the page, icons, "Untitled"; more than `MAX_CRUMBS` (4) → first, `Crumb::Gap`, last two. Unit tests.
- `leaf-ui` `shell/top_bar.rs`: the 44 px bar above the open page; crumbs open their page; `edited_ago` label,
  "just now" while edits are unstamped, a 30 s redraw timer, exact local time on hover (`chrono::Local`, already in
  the tree via gpui-component; the E18-S01 log asked to pick how the UI reads the offset); star toggles
  `set_favourite`; `⋯` dropdown with the Favourites item for now (E18-S04 adds the rest).
- ☰ reopen button moves into the bar's left end when a page is open (`reopen_sidebar_button`, shared with the
  floating one). Narrow windows: the title shrinks 50× faster than ancestors (capped at 180 px); the row clips.
- Window tests: no bar without a page; crumbs in the bar and opening ancestors; star toggles; ☰ before the
  crumbs; 560 px window keeps one line with the controls whole. Header test now measures from the bar.
- Screenshot tool: `deep`, `star` and `cover=NAME` options; screenshots with and without a cover (owner asked). ADR 0065; ARCHITECTURE updated.
