## Context

The `⋯` menu in the top bar holds the page's actions. Its items are one list in `leaf-editor` (label, icon,
shortcut, danger, enabled), so later stories add an item without building a new menu. The sidebar's right-click
menu runs the same actions.

## Acceptance criteria

- [x] Menu model in `leaf-editor`: Add to / Remove from Favourites, Rename, Move to Trash (red), and a footer with "Created …" and "Last edited …"; tested
- [x] Rename puts the caret in the page title with it selected; Move to Trash trashes the page and opens its parent (or the next page), with undo
- [x] Keyboard: arrows move, Enter runs, Escape closes; the menu closes on a click outside
- [x] The sidebar's right-click menu and this menu call the same editor actions (no duplicated logic)
- [x] Screenshots in the PR, light and dark
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor` `workspace_editor/page_menu.rs`: `PageAction`, `PageMenuIcon`, `MenuPlace`, `PageMenuEntry`
  (action, label, icon, shortcut, danger, enabled, separated) and `PageMenu` (entries + footer);
  `WorkspaceEditor::page_menu(page, place, now, offset)` — Favourites toggle, Rename, Move to Trash (red,
  separated), sidebar adds "Add page inside", top bar adds "Created …" / "Last edited …";
  `trash_and_open_next` opens the parent, else the next or previous sibling, else the first page. Unit tests.
- `leaf-ui` `shell/page_menu.rs`: draws the list into a `PopupMenu` for both the `⋯` (top bar) and the sidebar's
  right-click menu, and `Shell::run_page_action` carries out each action (no duplicated logic; the old sidebar
  menu is gone). Rename: top bar focuses the title with all selected, sidebar edits the row. Move to Trash:
  `trash_and_open_next`, then a "Moved to Trash" notice with Undo (restore + reopen), since workspace changes
  have no Cmd+Z yet. Keyboard comes from gpui-component's popup menu (arrows, Enter, Escape, click outside).
- Window tests: keyboard runs an entry and Escape closes; rename from the top bar and from the sidebar; trash
  opens the parent, notice has Undo, Undo restores and reopens; sidebar's Add page inside. Screenshot tool:
  `pagemenu` option. ADR 0065 amended; ARCHITECTURE updated.
