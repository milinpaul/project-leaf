## Context

Copy/cut/paste rich block fragments within the app.

## Acceptance criteria

- [x] Fragment format is versioned JSON
- [x] Paste mid-text splits block correctly
- [x] Round-trip copy→paste equals original subtree
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor/src/clipboard.rs` + `clipboard/fragment.rs`: `Fragment::{Text, Blocks}` with versioned JSON
  (`{"leaf_fragment": 1, ...}`, serde; readers refuse other versions); `copy`, `cut`, `paste`.
- Paste: one undo step; text keeps exactly its own marks; blocks mid-text split the line (first block joins the text
  before the caret, the rest of the line follows the last pasted text); on an empty paragraph the first block takes
  its place, so copy→paste round-trips.
- `leaf-editor` gains `serde`/`serde_json` (already workspace deps, wasm-ok).
- Tests: `clipboard/tests.rs`; ADR-030.
