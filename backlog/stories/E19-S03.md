## Context

Draw action items so they read differently from to-dos, and let the owner set the date, time and priority
with the mouse or keyboard. The look follows ADR 0027 (warm, calm, the green used sparingly).

## Acceptance criteria

- [x] A round check (to-dos keep the square box); clicking it ticks the item off: text muted and struck through, and the date stops being red
- [x] After the text, a small date chip (red when overdue) and a priority flag (High, Medium, Low in three calm colours; nothing for none); the hand pointer over them
- [x] Clicking the date chip, or a shortcut, opens a date picker popover: a month calendar, Today / Tomorrow / Next week, an optional time field, and Clear
- [x] Clicking the flag, or a shortcut, opens a priority menu (High, Medium, Low, None) that works with the arrow keys
- [x] An item with no date or priority shows faint "Add date" / flag buttons on hover only, so plain tasks stay calm
- [ ] Screenshots in light and dark; checked on macOS by the owner
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor`: `DatePicker` (the month shown, Monday-first week rows, previous/next month, quick picks Today /
  Tomorrow / Next week), `parse_time` (`9`, `9:30`, `0930`, `9pm`, `9:30 am`), and `PageEditor::set_task_due`,
  `set_task_time`, `set_task_priority` (one undo step each). `PriorityMenu` order and labels. Unit tests.
- `leaf-ui` `shell/task_row.rs`: the round check (click ticks), and after the text a date chip (`due_label`, red when
  `is_overdue`, today from the local clock) and a priority flag (three theme colours); faint "Add date" and flag
  buttons on hover when unset; the hand pointer on all of them.
- `shell/task_pickers.rs`: the date picker popover (month calendar, quick picks, a time field that takes Enter, Clear)
  and the priority menu (arrow keys, Enter, Escape), anchored under the chip; Cmd/Ctrl+Shift+D and Cmd/Ctrl+Shift+P
  open them for the caret's action item.
- Window tests for each; screenshots light and dark (Linux build under Xvfb, as the screenshot tool is macOS-only).
