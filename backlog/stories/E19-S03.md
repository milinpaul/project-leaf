## Context

Draw action items so they read differently from to-dos, and let the owner set the date, time and priority
with the mouse or keyboard. The look follows ADR 0027 (warm, calm, the green used sparingly).

## Acceptance criteria

- [ ] A round check (to-dos keep the square box); clicking it ticks the item off: text muted and struck through, and the date stops being red
- [ ] After the text, a small date chip (red when overdue) and a priority flag (High, Medium, Low in three calm colours; nothing for none); the hand pointer over them
- [ ] Clicking the date chip, or a shortcut, opens a date picker popover: a month calendar, Today / Tomorrow / Next week, an optional time field, and Clear
- [ ] Clicking the flag, or a shortcut, opens a priority menu (High, Medium, Low, None) that works with the arrow keys
- [ ] An item with no date or priority shows faint "Add date" / flag buttons on hover only, so plain tasks stay calm
- [ ] Screenshots in light and dark; checked on macOS by the owner
- [ ] Tests added; `just check` passes; docs updated if structure changed
