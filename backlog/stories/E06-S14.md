## Context

The `main` CI run after #67 is green on Linux and macOS but red on Windows:
`welcome::model::tests::paths_show_home_as_a_tilde_and_long_ones_are_shortened` got `\srv/notes/Team.leaf`.
`short_path` (E06-S09) kept the system's root (`\` on Windows) but always joined folders with `/`, so on
Windows the welcome screen showed paths with mixed separators.
