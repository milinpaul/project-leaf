## Context

The owner asked to cut testing time (2026-10-31). Measured on `main` (#199's run): Windows tests took 49 minutes,
three property tests that write real files ran 37–43 minutes each with `PROPTEST_CASES=10000` (2 minutes or less on
Linux), Linux and macOS about 6 minutes with the undo/redo round trip the longest at about 5 minutes, and locally the
tests run in about 15 s once built: the wait there is compiling and linking.

## Acceptance criteria

- [x] Windows CI runs property tests with fewer cases (500) while Linux and macOS keep 10,000; Windows tests finish in
      about 10 minutes
- [x] The undo/redo round trip runs in four parallel parts that share its cases, so the same number of cases runs in
      about a quarter of the time
- [x] Development builds carry less debug information, so linking is faster and `target/` smaller; measured before
      and after; line numbers still show in panics
- [x] ADR on the test-depth and build choices; `just check` passes

## Plan

- CI test job: `PROPTEST_CASES` from the matrix, 10,000 on Linux and macOS, 500 on Windows.
- `leaf-editor/src/history/round_trip_tests.rs`: the round trip as four tests sharing `PROPTEST_CASES` (proptest's
  `TestRunner`, since the macro's config is overridden by the variable).
- `Cargo.toml`: `[profile.dev] debug = "line-tables-only"`, dependencies `debug = false`; measure a one-crate rebuild
  of all tests and `target/debug` before and after (42 s and 18 GB before).
- ADR-XXX-E08-S17; TECH_STACK's proptest row.
