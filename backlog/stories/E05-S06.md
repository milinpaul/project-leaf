## Context

Convert external clipboard text into blocks.

## Acceptance criteria

- [x] Multi-line text → paragraphs
- [x] Markdown headings, lists, todos, quotes, code, links converted
- [x] Clipboard also gets plain text + markdown on copy
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor/src/clipboard/markdown.rs` + `markdown/inline.rs`: a small Markdown reader by the `BLOCK_MODEL.md`
  mapping (headings, lists, to-dos, quotes, fences, dividers, nesting, wrapped list lines; inline bold, italic,
  strike, code, links) and writer (`Fragment::to_markdown`, `to_plain_text`), escaping only what could read as
  formatting. No new dependency.
- `PageEditor::paste_text`: one line → into the line; more → blocks via `paste`; code blocks get the text as is.
- Tests: `markdown/tests.rs`, including the real story `story-E05-S01.md` (insta snapshot, paste through a page, copy
  back as Markdown). Report in `docs/screenshots/E05-S06-story-paste.md`. ADR 0032.
