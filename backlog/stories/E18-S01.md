## Context

The top bar shows "Edited 3 minutes ago". Leaf doesn't record that yet: the store's `updated_at` is when a document
was last saved on this computer, which isn't the same (it changes on compaction, and won't sync). Record each page's
last edit in the workspace document and turn it into words for display.

## Acceptance criteria

- [ ] ADR: where the edited time lives (page metadata in the workspace doc), what counts as an edit (blocks, title, icon, cover; not opening, scrolling or starring) and how two peers' times merge (the later wins)
- [ ] Page metadata gains `edited_at` (Unix ms); every page and block command that changes a page sets it, through commands only; older pages without it fall back to `created_at`; unknown fields kept (rule 5)
- [ ] Undo restores the content but not an older edited time (undo is an edit too)
- [ ] `leaf-editor` turns it into words: "Edited just now" (under a minute), "Edited 1 minute ago", "Edited 3 minutes ago", "Edited 2 hours ago", "Edited 100 days ago"; plus the full date and time for a hover label; tested at every boundary, with an injected clock
- [ ] PRODUCT_SPEC Phase 1 and BLOCK_MODEL updated; compiles for `wasm32-unknown-unknown`
- [ ] Tests added; `just check` passes; docs updated if structure changed
