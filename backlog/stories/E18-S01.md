## Context

The top bar shows "Edited 3 minutes ago". Leaf doesn't record that yet: the store's `updated_at` is when a document
was last saved on this computer, which isn't the same (it changes on compaction, and won't sync). Record each page's
last edit in the workspace document and turn it into words for display.

## Acceptance criteria

- [x] ADR: where the edited time lives (page metadata in the workspace doc), what counts as an edit (blocks, title, icon, cover; not opening, scrolling or starring) and how two peers' times merge (the later wins)
- [x] Page metadata gains `edited_at` (Unix ms); every page and block command that changes a page sets it, through commands only; older pages without it fall back to `created_at`; unknown fields kept (rule 5)
- [x] Undo restores the content but not an older edited time (undo is an edit too)
- [x] `leaf-editor` turns it into words: "Edited just now" (under a minute), "Edited 1 minute ago", "Edited 3 minutes ago", "Edited 2 hours ago", "Edited 100 days ago"; plus the full date and time for a hover label; tested at every boundary, with an injected clock
- [x] PRODUCT_SPEC Phase 1 and BLOCK_MODEL updated; compiles for `wasm32-unknown-unknown`
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Model** (`leaf-model`): page meta gains `edited_at` (Unix ms). `PageMeta::edited_at` reads it, falling back to
  `created_at` when missing; `CreatePage` sets it to `created_at`. New `WorkspaceCommand::MarkEdited { page, at }`
  writes it as its own commit with a `leaf:edited` origin that the workspace undo manager ignores, so undoing a rename
  never brings back an older time. A command, so it is saved and will sync; the model still never reads the clock.
- **Noticing page edits:** `PageDoc` remembers the version it was last stamped at (like `SavedVersion`), with
  `has_unstamped_edits()` / `mark_stamped()`. Undo and redo count, because they change the version. Loading a page
  and adding its first empty paragraph do not.
- **Editor** (`leaf-editor`): `WorkspaceEditor::stamp_edits(now)` applies `MarkEdited` for every page whose blocks
  changed, plus pages renamed or given a new icon or cover since the last call (kept in a set). `leaf-ui` calls it on
  the existing 100 ms autosave tick, before saving, so the stored time is within a tick of the keystroke.
- **Words:** `edited_ago(now, at)` gives "Edited just now" / "Edited 1 minute ago" / "Edited 3 minutes ago" /
  "Edited 2 hours ago" / "Edited 1 day ago" / "Edited 100 days ago" (days without an upper unit, as agreed).
  `edited_on(at, offset_minutes)` gives "30 Oct 2026, 14:05" for the hover label; the caller passes the local UTC
  offset (the crate stays clock- and zone-free for WebAssembly). Pure functions tested at every boundary.
- **Merging two peers:** Loro keeps one value per key. A stamp written after seeing the other peer's always wins;
  for two stamps made at the same moment without seeing each other, both peers agree on one of them and the next
  edit corrects it. Recorded in the ADR as a known, sync-only limit (no sync until E10).
- **Docs:** ADR 0059 (where the time lives, what counts as an edit, merging), BLOCK_MODEL workspace-doc keys and
  commands, PRODUCT_SPEC Phase 1, ARCHITECTURE keystroke flow.
- **Tests:** model (meta read/fallback, MarkEdited, undo excludes it, unknown fields kept, two-peer convergence
  proptest), page doc stamping (edit, undo, load), editor `stamp_edits` (blocks, rename/icon/cover, unchanged,
  undo is an edit), wording boundaries, wasm build.
- **Risk:** stamping every 100 ms tick while typing adds one small workspace commit per tick with edits; fine for
  size (compaction folds them) but checked with the existing autosave tests.
