## Context

Every story branch added its decision record's row as the last line of the index in `docs/adr/README.md`, so any two
open PRs with a record clashed there, and each needed a manual merge (owner, 2026-10-31: "fix it in this PR itself",
on #229).

## Acceptance criteria

- [x] Story branches leave the index alone; `scripts/adr_number.py` adds a numbered record's row from the record's
      heading, Type and Status
- [x] A row added the old way is renamed, not doubled
- [x] CLAUDE.md, CONTRIBUTING.md, the index's "How to add one" and the backlog skill say so
- [x] Tests added; the scripts' tests pass

## Plan

- `scripts/adr_number.py`: `add_index_rows` after the renames; tests in `scripts/test_adr_number.py`.
- Docs as above; a short decision record, ADR-084. Done in #229 at the owner's request.
