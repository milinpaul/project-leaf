## Context

On Linux GPUI shapes text with cosmic-text, whose fallback list puts `DejaVu Sans` before `Noto Color Emoji`.
DejaVu has black-and-white glyphs for the basic smileys, so 😀 and friends draw as outlines while newer emoji are
in colour. GPUI also refuses a font with no Latin letters as an element's font or as a listed fallback, so Leaf
can't simply ask for the emoji font. macOS and Windows are not affected. Found in E06-S05 (icon picker).
