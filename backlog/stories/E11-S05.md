## Context

Extend the quick switcher (E06-S04) into one search bar with title and full-text results. All behaviour lives here
as plain, testable Rust; `leaf-ui` only draws it. Results come in as plain data, so `leaf-editor` does not depend
on `leaf-search` and stays wasm-ok.

## Acceptance criteria

- [x] State: query, results grouped by page, selected row; empty query shows recently opened pages
- [x] Typing waits for a short pause before searching, using a clock-free policy like `Autosave` (time passed in)
- [x] Results from an older query never replace those of a newer one
- [x] Up/Down move the selection (wrapping), Enter opens the selected page at its block, Escape closes
- [x] `Cmd/Ctrl+K` decision: with a text selection it is the link action, otherwise it opens search; `Cmd/Ctrl+P` always opens search
- [x] View model snapshots with `insta`
- [x] Tests added; `just check` passes; coverage ≥ 90%

## Plan

- **Module** `leaf-editor/src/search_bar.rs` (+ `search_bar/` submodules and tests). `SearchBar` wraps the quick
  switcher's page snapshot (titles, icons, breadcrumbs, recent pages), so it stays wasm-ok and never reads the
  index itself.
- **Plain input data**: `SearchHit { page, title: Marked, title_matched, blocks: Vec<BlockMatch> }`. `leaf-ui`
  (E11-S06) converts `leaf_search::PageHit` into it; `leaf-editor` gains no dependency.
- **Typing**: `set_query(text, now)`. Title matches update at once (fuzzy, as in the switcher), and a full-text
  search falls due `SEARCH_DELAY_MS` after the last keystroke (a debounce). `next_deadline()` and
  `due(now) -> Option<SearchRequest { id, query }>` are for the app's timer. No clock and no threads.
- **Stale results**: each query gets a rising id; `deliver(id, hits)` ignores anything but the latest.
- **Rows**: grouped by page. Title-matched pages come first, then text-only ones. Each page row is followed by its
  matching blocks, and every row can be selected. Trashed or unknown pages are dropped. Highlights are byte ranges
  (FTS gives character ranges, which are converted).
- **Keys**: `press(SearchKey::{Up, Down, Enter, Escape}) -> SearchOutcome::{Nothing, Open(Destination), Close}`.
  Up and Down wrap. A `Destination` is a page plus an optional block.
- **Shortcut decision**: `shortcut_action(Shortcut::{ModK, ModP}, text_selected) -> ShortcutAction::{Link,
  OpenSearch}`.
- **Tests**:
  - unit tests;
  - `insta` snapshots of the rows;
  - a proptest where typing, timer ticks and late deliveries interleave, and shown results always belong to the
    current query.
- **Docs**: an ADR (search bar model), ARCHITECTURE, and the crate doc.
