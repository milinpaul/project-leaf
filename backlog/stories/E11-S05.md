## Context

Extend the quick switcher (E06-S04) into one search bar with title and full-text results. All behaviour lives here
as plain, testable Rust; `leaf-ui` only draws it. Results come in as plain data, so `leaf-editor` does not depend
on `leaf-search` and stays wasm-ok.

## Acceptance criteria

- [ ] State: query, results grouped by page, selected row; empty query shows recently opened pages
- [ ] Typing waits for a short pause before searching, using a clock-free policy like `Autosave` (time passed in)
- [ ] Results from an older query never replace those of a newer one
- [ ] Up/Down move the selection (wrapping), Enter opens the selected page at its block, Escape closes
- [ ] `Cmd/Ctrl+K` decision: with a text selection it is the link action, otherwise it opens search; `Cmd/Ctrl+P` always opens search
- [ ] View model snapshots with `insta`
- [ ] Tests added; `just check` passes; coverage ≥ 90%
