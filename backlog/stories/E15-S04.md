## Context

Draw a web bookmark as a card: title, description, domain with icon, and preview image at the side. Before or without
a fetch it shows the address and domain only.

## Acceptance criteria

- [ ] Clicking opens the address in the system browser; the block handle, selection and keyboard work like images
- [ ] Light and dark themes; long titles and addresses truncate
- [ ] Snapshot tests of the card view model
- [ ] Tests added; `just check` passes; docs updated if structure changed
