## Context

Draw a web bookmark as a card: title, description, domain with icon, and preview image at the side. Before or without
a fetch it shows the address and domain only.

## Acceptance criteria

- [x] Card shows title, two-line description, icon + domain, and the preview image; missing parts collapse cleanly
- [x] Without preview data the card shows the address and domain; while fetching, a subtle loading state
- [x] Clicking opens the address in the system browser; the block handle, selection and keyboard work like images
- [x] Light and dark themes; long titles and addresses truncate
- [x] Snapshot tests of the card view model
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor/bookmark_card.rs`: `WebBookmarkCard` (title or address, description, domain, pictures, fetched,
  fetching) and `domain_of`; insta snapshots as a readable picture of the card.
- `leaf-ui/shell/bookmark_card.rs`: the card (title truncated, description clamped to two lines, icon + domain,
  picture at the side with `object_fit(Cover)`; short without description or picture); selection border; hover;
  tooltip with the address; a click opens it (checked again) without moving the caret. `PageState::fetching` for
  the loading line, for E15-S05 to fill. Globe icon bundled.
- Demo workspace: the "Reading list" page gets three bookmarks (full preview with pictures in the asset store,
  words only, not fetched) for screenshots.
- Tests: view-model snapshots and domains; 4 window tests (card drawn, fetching line, click opens and keeps the
  caret, Delete above selects and Backspace deletes). PRODUCT_SPEC row, ARCHITECTURE.
