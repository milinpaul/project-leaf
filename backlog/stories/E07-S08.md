## Context

Display image with resize handles and caption.

## Acceptance criteria

- [x] Lazy-loads image, placeholder while loading
- [x] Resize persists width prop
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

1. **Editor (`leaf-editor`, plain Rust).** The view's `BlockStyle::Image` carries the asset and stored width.
   `image_display_size` (stored or natural width, shrunk to the room, height by shape), `resized_image_width`
   (start + pointer move, clamped to 64 px … room) and `PageEditor::set_image_width` (one undo step, nothing when
   unchanged). Unit tests for each.
2. **UI (`leaf_ui::shell::image_row`).** Draw the picture with GPUI's image loader (`use_asset`), which loads in the
   background when the row is first on screen; a "Loading image…" frame until then, "This image can't be shown" on a
   bad file. Record each image row's width while painting. A hover bar on the right edge drags (GPUI drag); the
   picture follows live; the width is saved on release, also when let go outside the page.
3. **Tests.** Window tests over a real workspace: placeholder then natural size, shrink to fit, stored width, damaged
   file, drag resizes live and saves once (one undo), click saves nothing, can't drag wider than the column.
4. **Docs.** ADR 0053, ARCHITECTURE.md paragraph, crate module docs. Real-app screenshots in the PR.
