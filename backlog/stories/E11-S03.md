## Context

Run a typed query against the index and return ranked, page-grouped results with excerpts.

## Acceptance criteria

- [x] Each typed word matches as a prefix ("pro" finds "project"); matching ignores case and accents ("cafe" finds "café")
- [x] User input can never break the query: FTS5 syntax characters are escaped; `"quoted words"` match as a phrase
- [x] Ranking: BM25, title matches above body matches, ties broken by most recently edited page
- [x] Results grouped by page (best few blocks per page), capped at a sensible limit
- [x] Each hit carries an excerpt and the character ranges of matched words, for highlighting
- [x] Empty query returns nothing (the search bar shows recent pages instead)
- [x] Tests added (including proptest: arbitrary input never errors); `just check` passes; coverage ≥ 90%

## Plan

Built together with E11-S04 in one PR (owner's request), on branch `story/E11-S03`.

- **Query (`query.rs`):** split the input into words and `"quoted phrases"`; drop pieces with no letters or
  digits; quote each one for FTS5 (inner `"` doubled) and add `*` so the last word of each piece matches as a
  prefix. All pieces must match (AND). Nothing left → no results. No user text reaches FTS5 unquoted.
- **Search (`search.rs`):** one query on page titles, one on blocks (limited), merged per page. A page whose
  title matches ranks above every body-only match; within a group, best BM25 first, then most recently edited.
  Up to 3 blocks per page, 50 pages. Titles via `highlight()`, blocks via `snippet()`, with control-character
  markers turned into char ranges (`Highlighted { text, ranges }`).
- **Where it runs:** `Searcher::open(workspace_root)`, a read-only connection the search bar (E11-S05/06) will
  use while the worker writes; WAL lets both run at once.
- **Schema:** `pages` gains `edited_at` and `saved_seq` (also used by E11-S04); `INDEX_VERSION` 2, so an old
  index is rebuilt. `index_page` takes the page's saved version.
- **Tests:** query unit tests + proptest (any input never errors), ranking/grouping/highlight tests.
