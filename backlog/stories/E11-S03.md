## Context

Run a typed query against the index and return ranked, page-grouped results with excerpts.

## Acceptance criteria

- [ ] Each typed word matches as a prefix ("pro" finds "project"); matching ignores case and accents ("cafe" finds "café")
- [ ] User input can never break the query: FTS5 syntax characters are escaped; `"quoted words"` match as a phrase
- [ ] Ranking: BM25, title matches above body matches, ties broken by most recently edited page
- [ ] Results grouped by page (best few blocks per page), capped at a sensible limit
- [ ] Each hit carries an excerpt and the character ranges of matched words, for highlighting
- [ ] Empty query returns nothing (the search bar shows recent pages instead)
- [ ] Tests added (including proptest: arbitrary input never errors); `just check` passes; coverage ≥ 90%
