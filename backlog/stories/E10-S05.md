## Context

Typing `[[` opens a popover that finds pages by title as you type, using the quick switcher's fuzzy matcher, and
inserts a link to the chosen page (PRODUCT_SPEC.md Phase 1; ADR 0071 answer 1).

## Acceptance criteria

- [ ] Typing `[[` opens the popover at the caret; the typed text filters pages (fuzzy, accents and case ignored), with icons and the parent page shown for duplicates
- [ ] Up/Down choose, Enter or click inserts the link in place of `[[` and the query, Esc closes and leaves the typed text
- [ ] When nothing matches exactly, a "New page '…'" entry creates the page inside the current page and links it (ADR 0071 answer 2)
- [ ] The slash menu gains "Link to page", opening the same popover
- [ ] Pages in the trash are not offered; the popover stays inside the window near the bottom edge
- [ ] Editor tests for the trigger, filtering and insert; window test; screenshots; `just check` passes
