## Context

Typing `[[` opens a popover that finds pages by title as you type, using the quick switcher's fuzzy matcher, and
inserts a link to the chosen page (PRODUCT_SPEC.md Phase 1; ADR 0071 answer 1).

## Acceptance criteria

- [x] Typing `[[` opens the popover at the caret; the typed text filters pages (fuzzy, accents and case ignored), with icons and the parent page shown for duplicates
- [x] Up/Down choose, Enter or click inserts the link in place of `[[` and the query, Esc closes and leaves the typed text
- [x] When nothing matches exactly, a "New page '…'" entry creates the page inside the current page and links it (ADR 0071 answer 2)
- [x] The slash menu gains "Link to page", opening the same popover
- [x] Pages in the trash are not offered; the popover stays inside the window near the bottom edge
- [x] Editor tests for the trigger, filtering and insert; window test; screenshots; `just check` passes

## Plan

- leaf-editor `link_menu.rs` (PageEditor): `[[` typed opens it (not in code); `link_query()` re-reads the `[[` and
  query from the text each time and closes on a `]`, a line break, the caret leaving, or a deleted bracket;
  `complete_link(page)` swaps them for a link in one undo step.
- leaf-editor `workspace_editor/link_menu.rs`: `link_menu()` (switcher matcher, max 8, not the open page or the
  trash, "New page" when no exact title), move/highlight/apply; "New page" creates the page inside the open one.
- Slash menu "Link to page" types `[[` and opens the menu. leaf-ui `link_menu_popover.rs` (placed like the slash
  popover), Up/Down/Enter/Escape in `page_keys.rs`.
- Tests: editor (opening, closing, completing, undo, choices, new page, slash entry); window tests; screenshots.
