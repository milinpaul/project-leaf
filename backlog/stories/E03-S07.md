## Context

Content-addressed image files under assets/.

## Acceptance criteria

- [x] Import file → AssetId (blake3)
- [x] Duplicate import stored once
- [x] Assets table records mime and size
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-store/src/assets.rs`: `Workspace::import_asset(bytes, now)` / `import_asset_file(path, now)`, `asset(id)`,
  `asset_path(id)`. Hash with `AssetId::of`; write `assets/<hash>` through a flushed temp file and rename (skip if
  a correct copy is there, repair a damaged one); then `INSERT OR IGNORE` the row (keeps the first record).
- `assets/kind.rs`: `image_mime` from magic bytes (PNG, JPEG, GIF, WebP, BMP, TIFF, AVIF, HEIC, SVG), no new
  dependency; `StoreError::NotAnImage` for anything else.
- Tests: import, dedupe (one file, one row, first record kept), refusal, repair of a damaged copy, import from a
  file, reopen; format detection table.
- Docs: ADR, ARCHITECTURE, BLOCK_MODEL.
