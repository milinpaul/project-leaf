## Context

Leaf's own visual identity: colors, type scale, spacing, radii, light/dark.

## Acceptance criteria

- [x] Tokens defined in one module
- [x] Follows system light/dark
- [x] Not a pixel copy of Notion — documented in an ADR with screenshots
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

**Owner interview (2026-10-29):** personality *warm & friendly*; *warm paper* neutrals; green accent used
*sparingly*; *soft charcoal* dark mode; *Inter + serif headings*; *soft 6-8 px* corners; *comfortable* density;
accent from the *icon's middle green* (#16A970, deepened for text). Goal: look premium, not a Notion copy.

- **Tokens (`leaf-ui/src/theme.rs`, one module):** light and dark `Palette`s (page, sidebar, hover, active,
  border, text, muted, faint, accent, accent hover, caret, selection, on-accent, code, accent-soft), type scale
  (Inter 16 px body, 1.6 line height; Source Serif 4 Display for title and H1-H3), radii 6/8 px, reading width
  720 px. Turned into gpui-component `ThemeConfig`s for light and dark.
- **Light/dark:** `leaf_ui::init` installs both and syncs with the system; the window re-syncs when the OS
  appearance changes (`observe_window_appearance`). `LEAF_APPEARANCE=light|dark` forces one, for screenshots.
- **Fonts:** Inter (Regular, Italic, SemiBold, Bold, BoldItalic) and Source Serif 4 Display Semibold, both OFL,
  in `crates/leaf-ui/assets/fonts/` with their licences, embedded with `include_bytes!` (~2.4 MB).
- **Apply:** page title and headings in the serif, reading column centred at 720 px, warm sidebar.
- **Tests:** every text/background pair meets WCAG AA (4.5:1 text, 3:1 UI) in both palettes; hex values parse;
  bundled fonts load and register their families.
- **ADR** with light/dark screenshots; ARCHITECTURE.md and crate doc.
