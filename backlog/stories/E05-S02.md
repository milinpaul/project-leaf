## Context

State machine for `/` menu: query, fuzzy filter, keyboard nav, apply.

## Acceptance criteria

- [x] Opens on `/` at word start, closes on Esc or space-with-no-match
- [x] Fuzzy filter with ranking tests
- [x] Apply converts empty block or inserts below
- [x] Query text removed on apply
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- New `leaf-editor/src/slash.rs` (+ `slash/items.rs`): the `/` and query stay page text; the editor keeps an anchor
  on the `/` and the highlight. `slash_menu()` reads the query and closes itself when the `/` goes or the caret
  leaves. Opens after typing `/` at a word start (not in code/captions); a space with no match closes it.
- Fuzzy filter written here (10 entries): name prefix > word/keyword prefix > letters in order (fewer gaps), ties in
  menu order.
- `slash_move`, `slash_close`, `slash_apply(index)`; `press(Enter)` applies while something matches. Apply removes
  `/query`, converts an empty block or inserts below; its own undo step.
- Tests: `slash/tests.rs`; ADR-026.
