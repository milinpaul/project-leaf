## Plan

- New `leaf-editor/src/keys.rs`: caret-driven handlers `press(Key)` for Enter, Cmd/Ctrl+Enter, Backspace,
  Delete, Tab, Shift+Tab, plus `delete_block` (a selected divider/image, or any block with its children). They reuse
  the existing `enter_at` / `backspace_at_start` / indent rules and the tracked caret from E04-S02.
- Mid-text Backspace/Delete remove one grapheme; a selection is deleted first.
- Code block: Enter inserts a newline; Cmd/Ctrl+Enter, or Enter at the end after two empty lines, leaves the block
  (trailing empty lines removed) into a new paragraph below.
- Dividers/images: Backspace after one, or Delete before one, selects it; a selected one is deleted with
  `delete_block`; Enter in an image caption adds a paragraph below.
- `leaf-model`: `PageDoc::as_one_step` groups several commands into one undo step (Loro undo groups), so
  "delete selection + split" and "leave code block" undo at once.
- Table rows covered elsewhere: arrows (E04-S03, tested there), paste (E05-S06).
- Tests: one per table row in `keys/tests.rs`, plus code, divider/image and undo-as-one-step tests.
