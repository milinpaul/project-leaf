## Context

Beside the table view model (E09-S04): a `BoardView` built from `DatabaseEditor`'s cached cells. Groups are "No
value" then each option of the grouping column in option order, minus hidden groups. Cards are in row order (or the
view's sort), after the view's filters, each with its title and the properties the view shows. A cell naming a
deleted option counts as "No value". Plain Rust, no UI:
- moving a card (cell and place) is one undo step;
- adding a card in a group creates a row with that group's value;
- the first screen of each group first, the rest as it is read.

## Acceptance criteria

- [ ] Grouping, card order, filters and hidden groups follow ADR 0075
- [ ] Card moves within and between groups, and new cards in a group, each one undo step
- [ ] Grouping by a deleted column asks for a property and keeps the setting
- [ ] 10,000 rows group within the ADR 0075 budget (benchmark)
- [ ] Tests added; `just check` passes
