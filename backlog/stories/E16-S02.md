## Context

Editing behaviour for tables in `leaf-editor` as plain, testable Rust: moving between cells, typing, and the
keys that add rows. Add the rules to PRODUCT_SPEC.md "Editor behaviour" and give each a test.

## Acceptance criteria

- [ ] Tab / Shift+Tab move to the next / previous cell; Tab in the last cell adds a row
- [ ] Arrow keys move within a cell's text, then to the neighbouring cell at the edge; Enter inserts a line break inside a cell
- [ ] Backspace in an empty table (or with the whole table selected) deletes it as one undo step
- [ ] Selecting across cells selects whole cells; copy, cut and delete act on those cells
- [ ] View model exposes the grid for the UI; insta snapshots for a few tables
- [ ] Rules added to PRODUCT_SPEC.md "Editor behaviour", each with a test
- [ ] Tests added; `just check` passes; docs updated if structure changed
