## Context

The page icon picker (`leaf_editor::emoji_picker`, `crates/leaf-ui/src/icon_picker.rs`, ADR 0034) can only be used
with the mouse after searching. While the search box has the keyboard, arrow keys should move a highlight through the
grid and Enter should pick the highlighted emoji.

## Acceptance criteria

- [x] The first result is highlighted as you type; Enter picks it
- [x] Left/Right move by one emoji, Up/Down by one row, across section boundaries; the highlight scrolls into view
- [x] Mouse hover moves the highlight too; Escape closes the picker
- [x] Navigation logic lives in `leaf_editor::emoji_picker` with unit tests
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf_editor::EmojiPicker`: a highlight (section, position), the first emoji after every search; `GridMove`
  (Left/Right by one across sections, Up/Down by a row in the same column across sections, `columns` passed by the
  UI); `highlight` for the mouse; Enter picks `highlighted_choice`. Unit tests.
- `icon_picker.rs`: draws the highlight, mouse moves it, `capture_action` takes gpui-component's MoveUp/Down/Left/
  Right from the search field and scrolls the row into view (`ScrollStrategy::Nearest`). Window test.
- ADR 0034 amended.
