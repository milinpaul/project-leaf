## Context

The page icon picker (`leaf_editor::emoji_picker`, `crates/leaf-ui/src/icon_picker.rs`, ADR 0034) can only be used
with the mouse after searching. While the search box has the keyboard, arrow keys should move a highlight through the
grid and Enter should pick the highlighted emoji.

## Acceptance criteria

- [ ] The first result is highlighted as you type; Enter picks it
- [ ] Left/Right move by one emoji, Up/Down by one row, across section boundaries; the highlight scrolls into view
- [ ] Mouse hover moves the highlight too; Escape closes the picker
- [ ] Navigation logic lives in `leaf_editor::emoji_picker` with unit tests
- [ ] Tests added; `just check` passes; docs updated if structure changed
