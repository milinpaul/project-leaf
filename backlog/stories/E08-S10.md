## Context

Found by a security and code-smell review of the repo tooling (2026-10-31). The repository is public, but
`ci.yml` runs with the default token scope, and the third-party actions are pinned to moving tags (`@v1`, `@v2`), so
a compromised action release would run in our CI. `deny.toml` also only warns on duplicate crate versions and unknown
git sources, so neither ever fails the build.

## Acceptance criteria

- [x] `ci.yml` declares `permissions: contents: read` at the top level; any job that needs more asks for it itself
- [x] Every third-party action is pinned to a full commit SHA, with the version tag in a comment
- [x] `.github/dependabot.yml` keeps `github-actions` and `cargo` up to date (weekly, grouped to limit PR noise)
- [x] `deny.toml`: `unknown-git = "deny"` (no git sources exist; GPUI comes from crates.io, so `allow-git` stays empty); `multiple-versions = "deny"` with a
      `skip` list for today's unavoidable duplicates, each with a reason
- [x] The owner is asked to turn on secret scanning and push protection in the repo settings (not doable from code)
- [ ] ADR recording the supply-chain policy; `just deny` and `just check` pass; PR CI green

## Plan

- `ci.yml`: top-level `permissions: contents: read`; pin all six third-party actions to the commit their tag points
  at today, with the exact version in a comment (typos: `v1` points at an untagged commit, so pin release v1.51.1).
- `.github/dependabot.yml`: weekly, grouped, for `github-actions` and `cargo`; it updates SHA pins and comments.
- `deny.toml`: `unknown-git = "deny"`. `Cargo.lock` has no git sources at all today (GPUI comes from crates.io as
  `gpui-pre`), so no `allow-git` entry is needed. `multiple-versions = "deny"`: about 89 crates appear twice, almost
  all inside GPUI's tree; use `skip-tree` for GPUI's crates (with reasons) and a short `skip` list for the rest.
- ADR 0073 (supply-chain policy), index entry; `SECURITY.md` mentions the policy.
- Test: `cargo deny check`, `just check`; PR CI proves the pinned actions resolve.
