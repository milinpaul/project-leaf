## Context

A page can have a cover: a full-width band above the title, like Notion. The icon sits over the cover's bottom
edge, half on it and half below. Agreed with the owner on 2026-10-29; polish, so it must not hold up the Phase 0
acceptance pass.

Store the cover on the page next to `title` and `icon` in the workspace doc, so the sidebar and header know it
without opening the page. Built-in covers are saved by a stable name (`builtin:<name>`), not as an image, so a
later "upload your own" can reuse the asset store without changing the format.

## Acceptance criteria

- [x] Workspace doc page meta gets an optional `cover`; `SetPageCover { page, cover: Option<String> }` sets or clears it as one undo step, and setting the same cover is `Unchanged`
- [x] An unknown cover name (from a newer version) is kept and shown as a neutral band, never dropped (rule 5); `cover` survives page moves, trash and restore
- [x] Header: on hover, **Add cover** sits beside **Add icon**; over a cover, **Change cover** and **Remove** appear
- [x] Change cover opens a picker popover with thumbnails of the built-in covers; choosing one applies it; Esc closes
- [x] With a cover the band is full width, about 200–240 px tall, and the icon overlaps its bottom edge; without one the header is unchanged
- [x] Covers are drawn in code (gradients/shapes) or from bundled vector files; the first step checks GPUI draws full-colour vector files and records the choice in an ADR
- [x] At least one placeholder cover so the story works before E06-S12
- [x] BLOCK_MODEL.md and ARCHITECTURE.md updated; ADR added
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Model (`leaf-model`):** `keys::COVER`, `PageMeta.cover: Option<String>` (read with the same type checks as
  `icon`), `WorkspaceCommand::SetPageCover { page, cover }` mirroring `SetPageIcon` (empty string rejected with
  `ModelError::EmptyCover`). The model stores any non-empty name; it doesn't know the catalogue, so names from newer
  versions survive. Tests: set/replace/clear, no-op is `Unchanged`, rejects, save/load, survives move/trash/restore,
  undo unit test, and the workspace undo property test gains a cover step.
- **Editor (`leaf-editor`):** `cover` module: `BuiltinCover` (catalogue: stable name, label; S11 ships `Dawn`, S12
  adds four) and `PageCover::{Builtin, Unknown}` parsed from the stored `builtin:<name>`. `WorkspaceEditor::set_cover`
  (no-op when unchanged) and `selected_cover`.
- **UI (`leaf-ui`):** covers are bundled SVG files drawn with GPUI's `img()` (`ObjectFit::Cover`); GPUI rasterises
  SVG in full colour, while its gradients take only two colours, too plain for designed covers. `covers/dawn.svg`
  placeholder. Header item: full-width band (220 px) above the column, icon pulled up to overlap its bottom edge;
  **Add cover** beside **Add icon**; **Change cover** / **Remove** on hover over the band; picker popover of
  thumbnails (`cover_picker.rs`), Esc closes. Unknown cover → neutral band. Window tests like the icon ones.
- **Docs:** BLOCK_MODEL.md (workspace meta + command), ARCHITECTURE.md (page header paragraph), ADR 0045 on how
  covers are stored and drawn.
- **Risks:** SVG rasterised at 2× intrinsic size, so covers are 1200×300 to stay sharp without huge textures;
  header height changes when a cover is added (the list re-measures visible items each frame).
