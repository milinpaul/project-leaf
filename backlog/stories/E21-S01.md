## Context

Add `BlockKind::Callout { tone }` to `leaf-model` with five tones (Info, Success, Warning, Error, Note), and the
editor rules for typing in one. A callout holds rich text with marks and no child blocks, like a quote.

## Acceptance criteria

- [x] `BlockKind::Callout { tone: CalloutTone }` stored as type `callout` with a `tone` string; documented in BLOCK_MODEL.md
- [x] A tone this version doesn't know is kept as stored when the page is saved (rule 5) and reads as an unknown tone the UI can draw grey
- [x] A command changes a callout's tone (one undo step); `SetBlockKind` turns blocks into and out of callouts, keeping their text and marks
- [x] Editing rules: `Enter` mid-text inserts a line break inside the callout; `Enter` on an empty last line leaves it (the empty line becomes a paragraph after it); `Backspace` at the very start turns it into a paragraph
- [x] Callout appears in the block menu's and formatting bar's "Turn into" list
- [x] Undo/redo round-trips and two-peer convergence covered (proptest); search indexes callout text (tests that used `callout` as an unknown type updated)
- [x] ADR written and added to the index; PRODUCT_SPEC block types and "Editor behaviour" updated
- [x] Tests added; `just check` passes

## Plan

- `leaf-model`: `CalloutTone` (five names + `Other(String)` kept as stored); `BlockKind::Callout { tone }`, prop key
  `tone`, `BlockProp::CalloutTone`; text with marks, no children; empty tone refused.
- `leaf-editor`: Enter adds `\n` (like code); Enter on an empty last line or in an empty callout leaves (trim the
  line, paragraph after); Mod+Enter leaves; Backspace at start → paragraph (existing rule). Callout in
  `turn_into_kinds` after Quote; clipboard fragment carries the tone; Markdown copy writes GitHub alerts.
- `leaf-ui`: compiles; callouts draw as plain text rows until E21-S02.
- Tests: model unit tests (tone, unknown tone kept through edit and save, kind changes, bad data), proptest kinds and
  props include callouts (undo round-trip, convergence), editor Enter/Backspace rules; tests that used `callout` as
  an unknown type now use `sticky_note`. ADR 0070, BLOCK_MODEL, PRODUCT_SPEC.
