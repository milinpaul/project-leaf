## Context

Add `BlockKind::Callout { tone }` to `leaf-model` with five tones (Info, Success, Warning, Error, Note), and the
editor rules for typing in one. A callout holds rich text with marks and no child blocks, like a quote.

## Acceptance criteria

- [ ] `BlockKind::Callout { tone: CalloutTone }` stored as type `callout` with a `tone` string; documented in BLOCK_MODEL.md
- [ ] A tone this version doesn't know is kept as stored when the page is saved (rule 5) and reads as an unknown tone the UI can draw grey
- [ ] A command changes a callout's tone (one undo step); `SetBlockKind` turns blocks into and out of callouts, keeping their text and marks
- [ ] Editing rules: `Enter` mid-text inserts a line break inside the callout; `Enter` on an empty last line leaves it (the empty line becomes a paragraph after it); `Backspace` at the very start turns it into a paragraph
- [ ] Callout appears in the block menu's and formatting bar's "Turn into" list
- [ ] Undo/redo round-trips and two-peer convergence covered (proptest); search indexes callout text (tests that used `callout` as an unknown type updated)
- [ ] ADR written and added to the index; PRODUCT_SPEC block types and "Editor behaviour" updated
- [ ] Tests added; `just check` passes
