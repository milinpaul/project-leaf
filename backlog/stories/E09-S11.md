## Context

E09-S05 lets a select or multi-select cell pick options and create new ones (in the next palette colour). The option picker should also let each option be renamed, given another colour, dragged into another order and deleted (cells that had it lose it), as `DatabaseCommand`s through `DatabaseEditor`. Found while building E09-S05.

## Acceptance criteria

- [ ] Each option in the picker has a menu: rename, colour (the nine palette colours), delete
- [ ] Options can be reordered by dragging in the picker
- [ ] Deleting an option clears it from every cell, as one undo step
- [ ] Tests added; `just check` passes
