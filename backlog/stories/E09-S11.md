## Context

E09-S05 lets a select or multi-select cell pick options and create new ones (in the next palette colour). The option picker should also let each option be renamed, given another colour, dragged into another order and deleted (cells that had it lose it), as `DatabaseCommand`s through `DatabaseEditor`. Found while building E09-S05.

## Acceptance criteria

- [x] Each option in the picker has a menu: rename, colour (the nine palette colours), delete
- [x] Options can be reordered by dragging in the picker
- [x] Deleting an option clears it from every cell, as one undo step
- [x] Tests added; `just check` passes

## Plan

- Model: `DatabaseCommand::MoveOption { column, option, index }` (the options list is a movable list). The option
  commands move out of `database/apply.rs` (over 400 lines) into `database/options.rs`.
- Editor (`DatabaseEditor`): `option_menu` (name, colour, the nine colours), `rename_option` (trimmed; empty or a
  name another option has is refused), `set_option_color` (palette colours only), `move_option`, and
  `delete_option`, which clears the option from every cell and deletes it as one undo step (`Database::group`).
- UI: a "⋯" on each option in the picker (table and row page) opens its menu: name field, the colours, Delete.
  With no search typed, options drag to a new place in the list.
- Tests: model (move, merges), editor (each action, refusals, delete clears cells and undoes in one step), window
  tests for the menu and dragging. Screenshots light and dark. ADR for the delete-clears-cells choice.
