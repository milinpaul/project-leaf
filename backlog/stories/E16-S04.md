## Context

Get tables in and out: the slash menu inserts one, pasting a markdown table makes one (ADR 0032 currently pastes
tables as text), and copying a table puts markdown on the clipboard. Be forgiving about tables copied with blank
lines between rows, as in the owner's example from ARCHITECTURE.md.

## Acceptance criteria

- [ ] `/table` inserts a 3 × 3 table with a header row, caret in the first cell
- [ ] Pasting a GFM table (header, `|---|` line, rows; with or without outer pipes; inline marks in cells) makes a table block
- [ ] A table whose rows are separated by blank lines still pastes as one table
- [ ] Copying a table writes a GFM markdown table; the internal clipboard keeps it as a table
- [ ] ADR 0032 updated: tables no longer paste as text
- [ ] Tests added; `just check` passes; docs updated if structure changed
