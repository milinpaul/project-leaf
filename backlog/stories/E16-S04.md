## Context

Get tables in and out: the slash menu inserts one, pasting a markdown table makes one (ADR 0032 currently pastes
tables as text), and copying a table puts markdown on the clipboard. Be forgiving about tables copied with blank
lines between rows, as in the owner's example from ARCHITECTURE.md.

## Acceptance criteria

- [x] `/table` inserts a 3 × 3 table with a header row, caret in the first cell
- [x] Pasting a GFM table (header, `|---|` line, rows; with or without outer pipes; inline marks in cells) makes a table block
- [x] A table whose rows are separated by blank lines still pastes as one table
- [x] Copying a table writes a GFM markdown table; the internal clipboard keeps it as a table
- [x] ADR 0032 updated: tables no longer paste as text
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **`/table`** (`slash.rs`, `slash/items.rs`): a "Table" entry (`SlashAction::Table`) adds a 3 × 3 table with a header
  row in place of an empty paragraph, or below the line; caret in the first cell; one undo step. Icon `Table` in
  `leaf-ui`.
- **Paste** (`clipboard/markdown/table.rs`): read GFM tables (header, delimiter with as many columns, rows; outer pipes
  optional; `\|`, `<br>`, inline marks). Blank lines between rows are skipped when the next row starts with `|`.
  `clipboard.rs` builds pasted tables with `InsertTable` and fills the cells; a table can't join a line's text, so it
  goes below the line (or replaces an empty paragraph). Into a cell: a line per cell.
- **Copy:** `Fragment::to_markdown` writes GFM, `to_plain_text` tab-separated rows; the wire fragment carries table
  kinds; selected cells copy as a table of those cells.
- **Tests:** `table/tests/in_and_out.rs`; old "paragraph per cell" tests replaced.
- **Docs:** ADR 0032 update, BLOCK_MODEL mapping, PRODUCT_SPEC rules, ARCHITECTURE tables paragraph.
