## Context

Owner request: see the block model (E02) working in the real window before the full editor (E04 cursor model,
E07-S02 rich text element) exists. Each page gets an in-memory `PageDoc`; its blocks render as a list with one plain
text input per block. **Interim**: replaced by the rich text element in E07-S02, so keep the UI thin and put the
logic in `leaf-editor`, where it carries over. Nothing is saved yet (E03).

## Acceptance criteria

- [x] Opening a page shows its blocks in reading order, indented by nesting, styled by kind (heading sizes, bullet, number, checkbox, quote bar, code font)
- [x] An empty page starts with one empty paragraph to type in
- [x] Typing edits the block's text through the text commands
- [x] Enter adds a block below (lists and to-dos keep their kind, others become paragraphs) and focuses it
- [x] Enter on an empty list item or to-do ends the list (outdent; at the top level, paragraph) instead of adding another (owner review)
- [x] Ticked to-dos are struck through (owner review)
- [x] Backspace in an empty block deletes it and focuses the block above (the last block stays)
- [x] Tab / Shift+Tab indent and outdent the focused block
- [x] A toolbar turns the focused block into paragraph, heading 1–3, bulleted, numbered, to-do, quote or code
- [x] Clicking a to-do's checkbox ticks it
- [x] Logic lives in `leaf-editor` with unit tests; `leaf-ui` only renders and forwards
- [x] Screenshots of the running app in the PR
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **`leaf-editor/src/page_editor.rs`:** `PageEditor` wraps a `PageDoc`.
  - `rows()` is the view model: blocks in reading order with depth, a `BlockStyle` (numbered items get their
    number here, never stored), and plain text.
  - Actions: `ensure_block` (empty page → one paragraph), `set_text` (diffs old and new text into minimal
    Delete/InsertText at Unicode positions), `enter`, `backspace_empty`, `indent`, `outdent`, `turn_into`,
    `toggle_checked`, `previous`/`next`. Unit tests for each.
- **`WorkspaceEditor`:** keeps one `PageEditor` per page, created when the page is first opened.
- **`leaf-ui` (`shell/blocks.rs`):**
  - One borderless `InputState` per block, kept in a map and refreshed from the model each frame. Typing →
    `set_text`.
  - Keys are intercepted in the capture phase on the page area: `Enter`, `Backspace` (only when empty),
    `IndentInline`/`OutdentInline` (Tab/Shift+Tab), and `MoveUp`/`MoveDown` between blocks, then stopped so the
    input doesn't also handle them.
  - Per-kind styling: heading sizes, `•` and `N.`, a `Checkbox` for to-dos, a quote bar, a monospace font for code,
    a line for dividers, placeholders for image and unknown blocks. A turn-into toolbar acts on the focused block.
- **Interim limits:** Enter always adds a block below (splitting text is E02-S05/E04-S05). Backspace only deletes
  empty, childless blocks. No inline formatting editing. The rich text element (E07-S02) replaces the inputs.
- **Checks:** GPUI tests for typing, Enter and Tab through the shell; run the app and screenshot several kinds.
