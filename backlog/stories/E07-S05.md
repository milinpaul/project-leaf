## Context

Drag preview and drop indicator.

## Acceptance criteria

- [x] Indicator shows before/after/nest
- [x] Auto-scroll near edges
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `shell/block_drag.rs`: GPUI `on_drag` on the handle (the menu moves to `on_click`), `on_drag_move` / `on_drop` on the
  page. The value is the grabbed block; the drag uses `action_targets`.
- Each row records its drawn bounds (`DrawnRows`); a drag move passes them to `PageEditor::drop_target` (E05-S04).
- Draw a 3 px line under the `below` row (or above the first row), indented to the depth; fade the dragged rows; the
  preview shows the first line and "+N".
- Auto-scroll: a timer while the pointer is within 48 px of the page's top or bottom edge, faster nearer the edge.
- Tests: window tests for drop, nest, letting go off the page, click still opening the menu, and auto-scroll; unit tests
  for the scroll speed and fading. Screenshots via a new `drag=B:T[:L]` option.
- Docs: ADR 0050, ARCHITECTURE.
