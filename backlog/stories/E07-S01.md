## Context

Virtualized list rendering of the view model.

## Acceptance criteria

- [x] Only visible blocks laid out
- [x] Correct indentation, bullets, numbers, checkboxes
- [x] 10k-block page scrolls smoothly
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-ui/src/shell/page_list.rs`: the page area becomes GPUI's variable-height `list` (title as item 0, blocks
  after), so only visible rows are laid out and get inputs. `changes(old, new)` diffs each frame's rows: re-measure
  rows whose content changed, splice the added/removed/moved run, keep scroll position; reset on another page.
- `shell/markers.rs`: bullets • ◦ ▪ and numbers 1. a. i. by depth. Row drawing moved to `shell/block_row.rs`.
- Focusing a block scrolls it into view.
- Tests: diff and marker unit tests; window tests with a 10,000-block page (only ~a screenful of rows built, at the
  top and after scrolling to the middle), edits keeping the list in step, and a scroll asked for right after
  opening a page. ADR-035.
- `leaf-ui/examples/screenshot.rs` (`just screenshot`): renders a workspace off screen with the real Metal renderer
  and saves a PNG (works with the screen locked); `bench` times frames while scrolling. On a 10,000-block page
  (release): ~2.9 ms median / 7.1 ms slowest per frame scrolling a line at a time; ~6.7 ms / 8.0 ms jumping.
