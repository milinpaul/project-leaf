## Context

Monospace block with language label.

## Acceptance criteria

- [x] Language picker
- [x] Tab inserts spaces inside code
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Editor (`leaf-editor/src/code_block.rs`):
  - `CODE_LANGUAGES` (fence names plus labels), `find_languages` (fuzzy), `language_label`;
  - `set_code_language` (SetProp, one undo step);
  - `code_tab`: Tab and Shift+Tab inside one code block indent or outdent the touched lines by 4 spaces, with just a
    caret inserting spaces. `press` tries it before nesting.
- UI (`shell/language_picker.rs`): the language label at the code row's top right on hover; a click opens the picker
  (search field and list, current language first). Enter takes the top match, a click picks, Escape or a click
  outside cancels.
- Tests: editor unit tests (caret and selection indent and outdent, undo, nesting elsewhere, languages); window tests
  (picker by typing and by click, cancel, Tab and Shift+Tab keys). Screenshots via a new `language=B` option.
- Docs: ADR 0054, ARCHITECTURE, PRODUCT_SPEC Tab rule.
