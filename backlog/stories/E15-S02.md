## Context

A new `web_bookmark` block type (ADR-080) holding the address and, once fetched, the preview. Stored like other blocks, so an
older Leaf keeps it untouched as an unknown kind.

## Acceptance criteria

- [x] `web_bookmark` kind (`BlockKind::WebBookmark`) with props `url`, `title`, `description`, `image` (AssetId), `favicon` (AssetId), `fetched_at`; no text, no children
- [x] Insert, change props and delete go through commands; a bad or non-http(s) address is refused
- [x] A `SetWebBookmarkPreview` command fills the preview, does nothing if the block is gone or its `url` changed, and is kept off the undo stack
- [x] Turning a web bookmark into a paragraph keeps the address as linked text; the reverse is allowed for a block that is only one link
- [x] Undo round-trip and two-peer convergence covered by property tests; unknown props kept (rule 5)
- [x] BLOCK_MODEL.md updated; compiles for `wasm32-unknown-unknown`
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-model/web_bookmark.rs`: `WebPreview`, `check_web_address`, read/write of the props (preview parts lenient).
- `BlockKind::WebBookmark { url, preview }`, `BlockProp::WebAddress` (clears the preview), `ModelError::InvalidWebAddress`.
- `PageCommand::SetWebBookmarkPreview`: no-op when the block moved on; commit origin `leaf-web-preview` excluded
  from undo, like repairs.
- Conversions in `kind_ops`: bookmark → its address as linked text; empty or only-one-link block → bookmark.
  The bookmark keeps an empty text container from creation (the undo property test caught redo losing the address
  when the container was made by the conversion: ADR-007's Loro behaviour). Invariant 2 and repair allow it.
- Editor: view style, clipboard fragment (with preview), Markdown copy `[title](url)`, block menu label; UI shows a
  muted placeholder line until E15-S04.
- Tests: model unit tests (15), proptest generators (kinds, `WebAddress`, a preview step for current or stale
  address; undo test compares outlines without previews), editor clipboard tests. BLOCK_MODEL.md, ADR-XXX-E15-S02.
