## Context

A new `web_bookmark` block type (ADR-XXX-E15-S01) holding the address and, once fetched, the preview. Stored like other blocks, so an
older Leaf keeps it untouched as an unknown kind.

## Acceptance criteria

- [ ] `web_bookmark` kind (`BlockKind::WebBookmark`) with props `url`, `title`, `description`, `image` (AssetId), `favicon` (AssetId), `fetched_at`; no text, no children
- [ ] Insert, change props and delete go through commands; a bad or non-http(s) address is refused
- [ ] A `SetWebBookmarkPreview` command fills the preview, does nothing if the block is gone or its `url` changed, and is kept off the undo stack
- [ ] Turning a web bookmark into a paragraph keeps the address as linked text; the reverse is allowed for a block that is only one link
- [ ] Undo round-trip and two-peer convergence covered by property tests; unknown props kept (rule 5)
- [ ] BLOCK_MODEL.md updated; compiles for `wasm32-unknown-unknown`
- [ ] Tests added; `just check` passes; docs updated if structure changed
