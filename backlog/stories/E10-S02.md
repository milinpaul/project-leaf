## Context

A link to a page is one placeholder character (U+FFFC) carrying a `page` mark whose value is the target's
`PageId` (ADR-071). This story adds it to the model, with no UI.

## Acceptance criteria

- [x] `page` mark configured with `ExpandType::None`; `Mark::PageLink(PageId)` / `MarkKind::PageLink`; refused in code blocks
- [x] `PageCommand::InsertPageLink { id, pos, page }` inserts the placeholder and its mark in one commit (one undo step)
- [x] Invariant: the placeholder always carries a `page` mark and the mark sits only on placeholders; `SetMark`/`RemoveMark` can't break it, `SplitBlock`/`MergeIntoPrevious`/`SetBlockKind` keep links whole (turning a block into code, or merging into code, drops only the links; undo brings them back)
- [x] `PageDoc::page_links()` lists every (block, target) link in reading order
- [x] Proptest: command sequences with links keep the invariant, round-trip undo/redo and converge between two peers
- [x] BLOCK_MODEL.md marks table and commands updated; tests added; `just check` passes

## Plan

- `text.rs`: `page` mark (`ExpandType::None`), `Marks::page: Option<PageId>`, `Mark::PageLink(PageId)`,
  `MarkKind::PageLink`, and `PAGE_LINK` (U+FFFC).
- New `page_doc/page_links.rs`:
  - `InsertPageLink { id, pos, page }` writes the placeholder and its mark in one commit;
  - `page_links()` lists every (block, target) in reading order;
  - the invariant check and the merge repair for links.
- Rules, so the invariant (new invariant 10: a placeholder always carries `page`, and `page` sits only on
  placeholders) can't break:
  - plain text containing U+FFFC is refused (`InsertText`, `ReplaceText`, `InsertBlock`);
  - `ReplaceText` never carries `page` onto new text;
  - `SetMark(PageLink)` only re-points ranges made entirely of placeholders;
  - `RemoveMark(PageLink)` is refused (delete the link instead);
  - split, merge and duplicate already move marks whole.
- **Code decision:** turning a block into code removes its links (code takes no marks). The same happens in the merge
  repair. Undo brings them back, and E10-S03's editor can swap a link for its title first.
- Merge repair: `page` comes off non-placeholders, bare placeholders go (only an older version could cause either).
- Tests: unit tests per rule; proptest steps for inserting links and for the page-link mark, in the invariants, undo
  and convergence suites. BLOCK_MODEL.md (marks table, commands, invariant 10).
