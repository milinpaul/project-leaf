## Context

A link to a page is one placeholder character (U+FFFC) carrying a `page` mark whose value is the target's
`PageId` (ADR 0071). This story adds it to the model, with no UI.

## Acceptance criteria

- [ ] `page` mark configured with `ExpandType::None`; `Mark::PageLink(PageId)` / `MarkKind::PageLink`; refused in code blocks
- [ ] `PageCommand::InsertPageLink { id, pos, page }` inserts the placeholder and its mark in one commit (one undo step)
- [ ] Invariant: the placeholder always carries a `page` mark and the mark sits only on placeholders; `SetMark`/`RemoveMark` can't break it, `SplitBlock`/`MergeIntoPrevious`/`SetBlockKind` keep links whole (turning a block with links into code either is refused or drops only the links: decided in the plan)
- [ ] `PageDoc::page_links()` lists every (block, target) link in reading order
- [ ] Proptest: command sequences with links keep the invariant, round-trip undo/redo and converge between two peers
- [ ] BLOCK_MODEL.md marks table and commands updated; tests added; `just check` passes
