## Context

The spike wrapped one `PageEditor` by hand. The web app needs proper, typed bindings over the core, built and checked
in CI, so its TypeScript never handles documents itself. Shape decided in ADR-XXX-E14-S02.

## Acceptance criteria

- [ ] A `leaf-web` crate (wasm-ok, `wasm-bindgen`) exposing, with TypeScript types:
  - a workspace: open from stored bytes, the page tree (rows), new page, rename, move, trash, favourites, from
    `WorkspaceEditor`
  - a page: open from a snapshot plus updates, typed text and keys, caret and selection moves, undo and redo, marks,
    the view rows for drawing (`PageView`), and changes since a version to store (updates, not whole snapshots)
- [ ] The two core gaps from the spike are closed in `leaf-model` / `leaf-editor` (they help desktop sync too):
  `PageDoc` exports and imports updates since a version; `PageEditor` takes in changes without losing its caret,
  selection or undo history; both with two-peer proptests
- [ ] CI builds the WebAssembly package, runs `wasm-opt`, and fails if the compressed size passes the ADR's budget
- [ ] A headless-browser smoke test in CI: load the package, type a line, read it back from the view rows
- [ ] Coverage for the new core code stays at or above 90%; `just check` passes
