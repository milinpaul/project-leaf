## Context

Tabs above a database page (and an inline database once E09-S09 is in): one per view, with its layout's icon and
name. Click to switch. "+" adds a table or board view. Each tab's menu renames, duplicates or deletes it. Drag to
reorder. The table draws with the open view's own sort, filters, hidden properties and widths. The open tab is
remembered per device (`view.json`, like E06-S19). Keyboard: switch tabs without the mouse.

## Acceptance criteria

- [ ] Tabs show every view; switching is instant on a 10,000-row database
- [ ] Add, rename, duplicate, delete and reorder views from the tabs, each one undo step
- [ ] Each table view keeps its own sort, filters, hidden properties and widths
- [ ] The open tab comes back when the database is opened again
- [ ] Screenshots in light and dark; tests added; `just check` passes
