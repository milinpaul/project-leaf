## Context

Create/open MyWorkspace.leaf/ with sqlite, assets/, search/.

## Acceptance criteria

- [x] Create new workspace at a path
- [x] Open existing workspace, error on invalid one
- [x] Lock file prevents two app instances opening the same workspace
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **`leaf-store/src/workspace.rs`:** a `Workspace` holding the folder path, the lock and the `Store`.
  - **`Workspace::create(path)`:** makes `path/` with `workspace.sqlite`, `assets/`, `search/` and `leaf.lock`. It
    refuses a path that already exists, unless it is an empty folder.
  - **`Workspace::open(path)`:** needs a folder that contains `workspace.sqlite`, otherwise it fails with
    `NotAWorkspace`. It recreates `assets/` or `search/` if they are missing, then opens the store (migrations run
    there).
- **Lock:** the standard library's OS file lock (`File::try_lock`) on `leaf.lock`, taken before SQLite is touched.
  - A second open fails with `AlreadyOpen`.
  - The OS releases the lock when the app quits or crashes, so a stale lock can never block the owner.
  - No new dependency.
- **`StoreError`** gains `Io`, `AlreadyExists`, `NotAWorkspace` and `AlreadyOpen`.
- **Tests:**
  - create;
  - open;
  - create refuses a non-empty path, and accepts an empty folder;
  - open refuses a missing path, a file, a folder without a database, and a corrupt database;
  - a second open is refused, and allowed again after the first is dropped;
  - missing subfolders are recreated.
- **Out of scope:** the UI still uses an in-memory workspace. Wiring a folder picker is later work.
