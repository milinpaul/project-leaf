## Context

Edit link URL and open in browser.

## Acceptance criteria

- [x] Cmd/Ctrl+K with text selected opens popover (without a selection it opens search, E11-S05)
- [x] Cmd/Ctrl+click opens link
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Editor (`leaf-editor/src/link.rs`): `PageEditor::link_at(Caret)` for Cmd/Ctrl+click; `openable_url(href)`, which
  allows only http, https and mailto, and adds https:// to a bare web address. Linking itself reuses `set_link`,
  `remove_link` and `active_marks`.
- UI (`shell/link_popover.rs`): `LinkPopover` view (address input, Open, Remove) anchored under the selection start;
  Enter saves, Escape or a click outside cancels; the page gets the keyboard back. Cmd/Ctrl+K's Link branch opens it.
- `rich_text`: Cmd/Ctrl+click on a link opens it with `cx.open_url` and keeps the caret.
- Tests: editor unit tests for `link_at` and `openable_url`; window tests for the popover and Cmd/Ctrl+click.
  Screenshots via a new `link` option in the screenshot tool.
- Docs: ADR 0051, ARCHITECTURE, PRODUCT_SPEC inline shortcuts.
