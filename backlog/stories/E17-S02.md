## Context

Dragging a selection across blocks stops at the edge of the visible area: blocks below (or above) can only be
selected if they're already on screen, because the page doesn't scroll while selecting. Dragging the mouse near or
past the top or bottom edge should scroll the page and keep extending the selection. Drag-to-move blocks
(`shell/block_drag`) may need the same.

## Acceptance criteria

- [ ] Dragging a selection near or past the bottom/top edge scrolls the page, faster the further out the mouse is
- [ ] The selection keeps growing to the block under the mouse while it scrolls, even if the mouse doesn't move
- [ ] Scrolling stops when the mouse button is released or comes back inside
- [ ] Dragging a block to move it scrolls the same way
- [ ] Shift+Arrow selection already keeps the focus block in view (check, and fix if not)
- [ ] Tests added; `just check` passes; docs updated if structure changed
