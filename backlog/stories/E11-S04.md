## Context

After autosave writes a page, re-index that page off the UI thread. Rebuild the whole index in the background when
`SearchIndex::open` reports one is needed. The index only reads documents.

## Acceptance criteria

- [ ] A page edit is searchable within 1 s of the edit, without blocking typing
- [ ] Renaming, trashing, restoring and permanently deleting a page update the index
- [ ] Full rebuild runs in the background on open; title search keeps working meanwhile
- [ ] Deleting `search/` while the app is closed loses nothing: it is rebuilt on next open
- [ ] An index error is logged and triggers a rebuild; it never blocks editing or saving
- [ ] Tests added; `just check` passes; ARCHITECTURE.md data-flow section updated
