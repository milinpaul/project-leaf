## Context

Phase 1 adds databases (PRODUCT_SPEC.md "Database (single view type: Table)"): typed properties, add/rename/reorder/hide
columns, sort and filter, inline cell editing, each row a page, a database as a full page or inline in a page. Before
writing the E09 stories, prove a data model on Loro the way E00-S05 did for blocks: where a database's schema and
cells live, how they merge between two devices, how unknown property types survive, and whether a 10,000-row
database loads, sorts and filters fast enough. Throwaway-quality tests only; no production code.

## Acceptance criteria

- [x] Spike tests (Loro directly, no production code) show schema and cells in one database document: column order,
      typed values, rows as page IDs
- [x] Two-peer tests: concurrent cell edits, column rename vs cell edit, column delete vs cell edit, multi-select adds,
      row reorder vs row delete all converge to a sensible result
- [x] A property type from a newer version survives an older peer's edits untouched
- [x] Undo of a cell edit and of a column delete restores the exact earlier state
- [x] Measured: snapshot size, load, read, sort and filter of a 10,000-row × 8-column database (release build)
- [x] Proposed ADR with the data model, findings and the open product questions for the owner
- [x] E09 stories written from the findings (status `backlog`)
- [x] Tests added; `just check` passes

## Plan

- `crates/leaf-model/tests/database_spike/` (test target, Loro directly, no production code): `main.rs` holds a tiny
  `Db` helper over one Loro document (`columns`, `schema`, `rows`, `cells`) plus the save/load, unknown-type and
  undo tests; `merges.rs` two-peer cases; `perf.rs` an ignored 10,000-row measurement run in release.
- Record the model, findings, measurements, alternatives and open owner questions in ADR 0066 (Proposed).
- Write E09-S02..S10 as `backlog` stories from the findings; update the E09 epic notes.
- Risk: Loro merge semantics differ from what the model assumes. Note them as findings rather than redesign here.
