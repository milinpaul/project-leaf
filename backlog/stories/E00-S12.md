## Context

ADRs were named `NNNN-title.md`, and agents working in parallel picked the same next number (0061, 0063 and 0074
clashed), causing merge conflicts and renames. The owner wants the order kept and the story in the name, for every
ADR, old and new (2026-10-31): `ADR-001-E08-S08-bundled-code-font.md`.

## Acceptance criteria

- [x] Every ADR is renamed `ADR-NNN-<story>-<title>.md` (three-digit order number, the first story it records or its
      epic, then the old title part; none when it has no story), and its heading reads `# ADR-NNN. Title`
- [x] Every link and mention in code, docs and stories follows (`ADR 0068` becomes `ADR-068`); the index lists them
      in order with the new names; the template, CLAUDE.md and `docs/README.md` describe the new naming
- [x] Branches never pick a number: a new record is `ADR-XXX-<story>-<title>.md` until it merges, and the follow-up
      PR that marks its story done gives it the next number and updates every mention (owner's choice, 2026-10-31;
      a workflow pushing to `main` was tried first and refused by the `main` ruleset)
- [x] The numbering script has tests; CI stays read-only (ADR-073); the decision is recorded in an ADR named the
      new way

## Plan

- A one-off script renamed every `docs/adr/NNNN-title.md` to `ADR-NNN-<story>-<title>.md` and rewrote links and
  mentions everywhere (`ADR 0068` to `ADR-068`, `ADRs 0001-0005` to `ADR-001 to ADR-005`).
- `scripts/adr_number.py` (+ `test_adr_number.py`): numbers `ADR-XXX-*` records after the highest and rewrites
  `[ADR-XXX](file)`, the file name, the heading and `ADR-XXX-<story>` mentions; refuses two new records for one story.
- `.github/workflows/adr-numbers.yml`: on a push to `main` that adds an `ADR-XXX` file, run it and push the commit;
  queued one at a time, retried from the newest `main` if a push loses a race.
- A CI check for duplicate numbers was tried and dropped: it reports clashes but doesn't prevent them.
- Docs: template, index instructions, CLAUDE.md, `docs/README.md`; ADR-076 records it; ADR-073 notes the one
  job that may push.
