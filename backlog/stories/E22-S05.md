## Context

Draw a board view in `leaf-ui`:
- one column per group, with a count and the option's colour;
- cards in a virtual list per column, and the board scrolls sideways;
- drag a card within or between columns, with a drop line;
- "+ New" at the foot of each column;
- a click on a card opens its row (E09-S08);
- the board's menu picks the grouping property, hides groups and chooses what cards show;
- dragging a board column reorders the select's options, so every view agrees (owner, ADR-075 answer 3; needs
  E09-S11).

## Acceptance criteria

- [ ] Columns and cards drawn from the board view model, smooth with 10,000 rows
- [ ] Cards drag within and between columns with the mouse; keyboard moves too
- [ ] New card per column; open a card as a page
- [ ] Group-by, hidden groups and card properties set from the board's menu
- [ ] Screenshots in light and dark; tests added; `just check` passes
