## Context

Found by a security and code-smell review of the repo tooling (2026-10-31). The workspace already denies `unsafe`
and warns on `unwrap`/`expect` and `clippy::pedantic`, but panics can still hide in slice indexing, arithmetic
overflow and lossy casts, and about 16 `#[allow]` attributes carry no stated reason.

## Acceptance criteria

- [x] Workspace lints add: `allow_attributes_without_reason`, `panic`, `unreachable` (outside tests),
      `print_stdout`/`print_stderr` (outside examples and benches), `cast_possible_truncation`, `cast_sign_loss`
- [x] Core crates also lint `indexing_slicing` and `arithmetic_side_effects`; each hit is fixed or kept with an
      `#[expect(..., reason = "...")]` that says why it can't fail
- [x] Every existing `#[allow]` gets a reason or is removed
- [x] No behaviour change: all tests and snapshots pass unchanged
- [x] Code conventions in `CLAUDE.md` updated; ADR on the lint set; `just check` passes

## Plan

- **Workspace lints** (`Cargo.toml`): `allow_attributes_without_reason`, `panic`, `unreachable`, `print_stdout`,
  `print_stderr`, and `cast_possible_truncation`/`cast_sign_loss` named explicitly (they were already on through
  `pedantic`). `clippy.toml` lets tests panic, index and print; examples and benches may print (file-level allow
  with a reason). Measured: about 40 hits outside the core crates' indexing and arithmetic.
- **Core crates** (`leaf-core`, `leaf-model`, `leaf-editor`, `leaf-store`, `leaf-export`, `leaf-search`):
  `#![cfg_attr(not(test), warn(clippy::indexing_slicing, clippy::arithmetic_side_effects))]` in each `lib.rs`, so
  library code is checked and unit tests are not. Measured: 332 hits in 61 files, most in `leaf-editor`
  (Markdown inline parsing alone has 59).
- **Fixing:** `get`, iterators and pattern matching instead of indexing; `checked_*` where the function already
  returns `Option`/`Result`; `saturating_*` where clamping is the meaning (positions, counts); otherwise
  `#[expect(..., reason = "...")]` on the smallest item, saying why it can't fail. A fix only ever changes what
  happens in a case that used to panic.
- **Allows:** the 8 existing `#[allow]`s get reasons (or become `#[expect]`), or go.
- **Docs:** CLAUDE.md code conventions, CONTRIBUTING, ADR-XXX-E08-S15.
- **Risk:** size. Work is split by file between helpers; tests and snapshots must pass unchanged.
