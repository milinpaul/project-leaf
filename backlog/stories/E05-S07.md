## Context

Insert image from file or paste; caption editing.

## Acceptance criteria

- [x] Insert via slash menu and paste of image data
- [x] Asset stored via asset store
- [x] Caption editable as text
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor`: slash entries get an action (`SlashAction::Block`/`Image`); "Image" removes `/image` and records an
  anchored request the UI takes once (`take_image_request`, `cancel_image`). `PageEditor::insert_image(asset)` turns
  an empty block into the image or adds it below, caret in the caption, one undo step. `paste_kind` decides
  fragment → text → picture.
- `leaf-ui`: `shell::image` opens `prompt_for_paths`, imports via `Storage::import_image(_file)` (asset store, ADR
  0047) and calls `insert_image`; paste reads text, image and copied-file entries separately; image rows draw a
  frame + editable caption (picture itself is E07-S08).
- Tests: editor unit tests (placement, slash request, cancel, undo, caption typing, paste choice); window tests over
  a real folder (pasted screenshot stored and inserted, text wins, non-image file pastes as path, slash → picker →
  file inserted, cancel).
- Docs: ADR 0051, ARCHITECTURE.md.
