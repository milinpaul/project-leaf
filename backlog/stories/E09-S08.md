## Context

Opening a row shows its page: title, the row's properties listed under it (editable), then the page body as usual. Breadcrumb shows the database.

## Acceptance criteria

- [x] A row opens as a page with its properties above the body
- [x] Editing a property there changes the table
- [x] Tests added; `just check` passes
