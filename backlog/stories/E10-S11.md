## Context

The owner asked (2026-10-31) for a pointing-hand cursor when hovering a link in a page: page links open on a click,
and web links on Cmd/Ctrl+click, but the cursor stays the text I-beam over both, so nothing says they can be clicked.

## Acceptance criteria

- [x] Over a page link (live or in the trash) the cursor is a pointing hand; over a link to a deleted page, the I-beam
- [x] Over a web link the cursor is a pointing hand
- [x] Everywhere else in text the cursor stays the I-beam, and it goes back as soon as the pointer leaves the link
- [x] Window tests; `just check` passes

## Plan

- `LinkedText` (leaf-editor) also says where web links are drawn, so `PaintedLayout::link_kind_at` can tell what is
  under the pointer: a page link, a web link, or text.
- `Shell` remembers which block's link the pointer is over (set on mouse move over a text row); that row draws with
  `cursor_pointer` instead of `cursor_text`.
