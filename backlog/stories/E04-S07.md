## Context

Cmd+B/I/E, Shift+S, Cmd+K behaviour.

## Acceptance criteria

- [x] Toggle applies or removes based on whole selection state
- [x] Cursor-only toggle affects next typed text
- [x] Link create, edit, remove
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- New `leaf-editor/src/format.rs`: `toggle_mark(MarkKind)` over the selection (text across blocks or whole blocks):
  remove if every character has it, else apply; code blocks left out; one undo step.
- Caret-only toggle: kept as pending marks tied to the caret; `insert_text` applies them in the typing's undo step
  and carries them while typing; any caret move drops them.
- Links: `set_link` (selection, or the whole link at the caret; blank = remove), `remove_link`, `link_at_caret`
  for the popover. `active_marks()` for the toolbar.
- Tests: `format/tests.rs`; ADR 0022.
