## Context

`backlog.py serve` regenerates `backlog/backlog.json` whenever story files change, using the Python code it loaded
at start-up. Switching git branches changes story files, so the server rewrites the tracked JSON with whatever
code it is running, leaving a dirty working tree that blocks `git pull`. Found during E00-S02.
