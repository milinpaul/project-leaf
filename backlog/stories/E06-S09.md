## Context

A polished start page that makes Leaf feel premium, like the start screens of Obsidian, Linear or Arc. It is
where you create, open and switch workspaces. Spec: "Create or open a workspace (a local directory)".

## Acceptance criteria

- [x] **When it shows:**
  - first launch;
  - when the last workspace is missing or can't be opened (e.g. "already open"), with the reason;
  - from File → "Switch Workspace…".

  Otherwise Leaf reopens the last workspace directly.
- [x] **Layout:**
  - app mark and name, with a short tagline;
  - three clear actions: **Create new workspace**, **Open existing folder**, and **Open recent**;
  - the recent list shows each workspace's name, its shortened path and when it was last opened.
- [x] **Create:** pick a name and location (default `~/Documents/Leaf`), then the workspace opens straight away.
- [x] **Open:** the native folder dialog. A folder that isn't a Leaf workspace gets a clear message, with an offer
  to create one there if it's empty.
- [x] **Recent:**
  - click or Enter opens a workspace;
  - missing ones are greyed out with "Locate…" and "Remove";
  - fully usable from the keyboard (arrows, Enter).
- [x] **Look and feel:**
  - follows the system's light and dark theme;
  - generous spacing and a subtle entrance animation;
  - no layout jumps;
  - looks right at small and large window sizes.
- [x] **Menu:** "New Workspace…", "Open Workspace…", "Open Recent" and "Switch Workspace…" (Cmd/Ctrl shortcuts).
- [x] **Sidebar switcher:** clicking the workspace name at the top of the sidebar (shown with a ⇕ mark) opens a
  menu of recent workspaces (the open one ticked), then New workspace…, Open workspace… and All workspaces…, each
  with its shortcut.
- [x] **Verified with screenshots** in light and dark, on the first launch, with recent workspaces, and in the
  error states.
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Store**: `Workspace::inspect(path)` (workspace / empty folder / other folder / missing) and
  `new_workspace_path(location, name)` (trims, rejects empty or unsafe names, adds `.leaf`, refuses an existing path).
- **App root (`leaf-ui/src/app.rs`)**: an `AppView` that shows either the welcome screen or a workspace's shell and
  switches between them (dropping the shell saves and releases the folder lock). Launch: a named path opens; else
  the last workspace if present; otherwise (or on any error) the welcome screen, with the reason.
- **Welcome (`leaf-ui/src/welcome.rs` + `welcome/`)**: brand column (icon, name, tagline, Create / Open actions) and a
  Recent column (name, `~`-shortened path, "opened 5 min ago"; missing ones greyed with Locate… and Remove).
  Arrow keys and Enter on the list. Create form: name + location (default `~/Documents/Leaf`, "Change…" uses the
  native folder dialog). Open uses the native folder dialog; non-workspace folders get a clear message, empty ones an
  offer to create there. Entrance fade-up; stacks to one column in narrow windows.
- **Menus**: File → New Workspace… (Shift+Cmd/Ctrl+N), Open Workspace… (Cmd/Ctrl+O), Open Recent (submenu, rebuilt
  when the list changes), Switch Workspace… (Shift+Cmd/Ctrl+O).
- **Tests**: store helpers; pure welcome helpers (short path, list selection); GPUI: first launch shows welcome,
  open recent, missing greyed + remove, create, errors (already open, not a workspace), switch back.
- **Docs**: ADR, ARCHITECTURE, screenshots (first launch, recents, errors; light and dark).
