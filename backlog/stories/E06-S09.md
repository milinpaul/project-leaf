## Context

A polished start page that makes Leaf feel premium, like the start screens of Obsidian, Linear or Arc. It is
where you create, open and switch workspaces. Spec: "Create or open a workspace (a local directory)".

## Acceptance criteria

- [ ] **When it shows:**
  - first launch;
  - when the last workspace is missing or can't be opened (e.g. "already open"), with the reason;
  - from File → "Switch Workspace…".

  Otherwise Leaf reopens the last workspace directly.
- [ ] **Layout:**
  - app mark and name, with a short tagline;
  - three clear actions: **Create new workspace**, **Open existing folder**, and **Open recent**;
  - the recent list shows each workspace's name, its shortened path and when it was last opened.
- [ ] **Create:** pick a name and location (default `~/Documents/Leaf`), then the workspace opens straight away.
- [ ] **Open:** the native folder dialog. A folder that isn't a Leaf workspace gets a clear message, with an offer
  to create one there if it's empty.
- [ ] **Recent:**
  - click or Enter opens a workspace;
  - missing ones are greyed out with "Locate…" and "Remove";
  - fully usable from the keyboard (arrows, Enter).
- [ ] **Look and feel:**
  - follows the system's light and dark theme;
  - generous spacing and a subtle entrance animation;
  - no layout jumps;
  - looks right at small and large window sizes.
- [ ] **Menu:** "New Workspace…", "Open Workspace…", "Open Recent" and "Switch Workspace…" (Cmd/Ctrl shortcuts).
- [ ] **Verified with screenshots** in light and dark, on the first launch, with recent workspaces, and in the
  error states.
- [ ] Tests added; `just check` passes; docs updated if structure changed
