## Context

The viewer needs the workspace in a form a browser can fetch: the workspace document, each page's document and
the images they use. Define a versioned, read-only "web bundle" (a folder of static files) and the pure-Rust
code that builds and reads it, so it compiles for both desktop and WebAssembly. Trashed pages are left out.

## Acceptance criteria

- [ ] Bundle layout documented (manifest with format version, one Loro snapshot per page, assets by hash)
- [ ] Building a bundle from a workspace and reading it back gives the same pages, blocks and order (round-trip test)
- [ ] Unknown block kinds and properties survive the round trip (rule 5)
- [ ] Trashed pages are not included; a bundle with a newer format version is refused with a clear error
- [ ] Builder and reader compile for `wasm32-unknown-unknown`; no file system access in the shared code
- [ ] Tests added; `just check` passes; docs updated if structure changed
