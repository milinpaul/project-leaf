## Context

Debounced flush every 300 ms max, plus flush on blur and quit.

## Acceptance criteria

- [x] Flush policy unit-tested with a fake clock
- [x] No write when nothing changed
- [x] Explicit flush API for app shutdown
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **`leaf-store/src/autosave.rs`:** `Autosave`, a small, clock-free policy object. Times are passed in (Unix ms),
  so tests use a fake clock.
  - **`changed(key, now)`:** call after each command; remembers when each document first became unsaved.
  - **`next_deadline()`:** when the app's timer should next fire.
  - **`due(now)`:** the documents unsaved for at least 300 ms.
  - **`save(store, key, doc, now)`:** saves one document through `Store::save` and clears it.
  - **`pending()`:** every unsaved document, for flushing on blur and quit.
- **Throttle, not debounce:** the deadline is set by the *first* unsaved change, so steady typing can't put a save
  off past 300 ms (the spec's 1 s durability).
- **No write when nothing changed:** clean documents are never due, and `Store::save` writes nothing for a
  document without unsaved changes.
- **Out of scope:** opening a folder and running the timer in the app is new story E03-S08.
