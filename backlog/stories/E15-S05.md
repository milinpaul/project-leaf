## Context

A native crate that fetches a page's preview in the background, within the limits from the ADR, and saves the
result into the bookmark through a command. Images go into the workspace's asset store.

## Acceptance criteria

- [ ] Reads the title, description, preview image and icon (Open Graph tags, then `<title>`/meta, then the favicon)
- [ ] Enforces the ADR limits: http(s) only, timeouts, size cap, no local-network addresses, no JavaScript
- [ ] Runs off the UI thread; typing never waits; a failed fetch leaves the bookmark showing its address
- [ ] "Refresh preview" in the block menu fetches again
- [ ] Tests use a local test server and fixed HTML pages; no real internet in tests
- [ ] Core crates still have no network access; ARCHITECTURE.md describes the new crate
- [ ] Tests added; `just check` passes; docs updated if structure changed
