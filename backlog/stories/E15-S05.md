## Context

`leaf-fetch`, a native crate that fetches a page's preview in the background, within the limits from
ADR-080, and saves the result into the web bookmark through `SetWebBookmarkPreview`. Images go into the
workspace's asset store. Start from the trial on branch `spike/E15-S01-trial` (`crates/web-bookmark-spike/`):
resolver, limits, tokenizer and local test server.

## Acceptance criteria

- [ ] Reads the title, description, preview image and icon (Open Graph tags, then `<title>`/meta, then the favicon)
- [ ] Enforces the ADR limits: http(s) only, no user:password addresses, 5 redirects, 5 s connect / 10 s total, 512 KiB of HTML, 5 MiB image, 1 MiB icon, content types, no local-network addresses (checked in the resolver, every hop), no JavaScript, direct connection only
- [ ] `ureq` pinned exactly (its resolver hook is semver-exempt); `deny.toml` licence exception for `webpki-roots` only; `just deny` passes
- [ ] Non-UTF-8 pages decoded by header or `<meta charset>` (`encoding_rs`)
- [ ] Runs off the UI thread; typing never waits; a failed fetch leaves the web bookmark showing its address
- [ ] "Refresh preview" in the block menu fetches again
- [ ] Tests use a local test server and fixed HTML pages; no real internet in tests
- [ ] Core crates still have no network access; ARCHITECTURE.md describes the new crate
- [ ] Tests added; `just check` passes; docs updated if structure changed
