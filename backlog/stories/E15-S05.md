## Context

`leaf-fetch`, a native crate that fetches a page's preview in the background, within the limits from
ADR-080, and saves the result into the web bookmark through `SetWebBookmarkPreview`. Images go into the
workspace's asset store. Start from the trial on branch `spike/E15-S01-trial` (`crates/web-bookmark-spike/`):
resolver, limits, tokenizer and local test server.

## Acceptance criteria

- [x] Reads the title, description, preview image and icon (Open Graph tags, then `<title>`/meta, then the favicon)
- [x] Enforces the ADR limits: http(s) only, no user:password addresses, 5 redirects, 5 s connect / 10 s total, 512 KiB of HTML, 5 MiB image, 1 MiB icon, content types, no local-network addresses (checked in the resolver, every hop), no JavaScript, direct connection only
- [x] `ureq` pinned exactly (its resolver hook is semver-exempt); `deny.toml` licence exception for `webpki-roots` only; `just deny` passes
- [x] Non-UTF-8 pages decoded by header or `<meta charset>` (`encoding_rs`)
- [x] Runs off the UI thread; typing never waits; a failed fetch leaves the web bookmark showing its address
- [x] "Refresh preview" in the block menu fetches again
- [x] Tests use a local test server and fixed HTML pages; no real internet in tests
- [x] Core crates still have no network access; ARCHITECTURE.md describes the new crate
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `crates/leaf-fetch` from the trial: `Fetcher::preview` (page `<head>`, then picture ≤ 5 MiB and icon ≤ 1 MiB, drawable
  types only), `guard::PublicOnly` in the DNS lookup, `text::decode` (header, `<meta charset>`, UTF-8), limits per
  ADR-080; 11 tests against a local server. Workspace deps (`ureq =3.5.0`, `html5ever =0.27.0`, `url`, `encoding_rs`)
  and the `webpki-roots` licence exception; `cargo deny` passes.
- Opt-in gate now: `AppSettings::web_previews` (missing until answered, allowed only if `true`; S06 adds the UI).
- Editor `preview_requests.rs`: a request per bookmark made here (offer, address box, Turn into) or "Refresh preview"
  (shown only when allowed); handed out only while allowed; `set_web_bookmark_preview` wraps the command.
- UI `shell/preview_fetch.rs`: after each page action, takes requests, runs the fetcher on the background executor,
  stores pictures, saves the preview; the card shows "Fetching preview…" meanwhile. 4 window tests with a local
  server (fetches, nothing online when not allowed, a failure leaves the address, Refresh fetches again).
- ARCHITECTURE (crate table, data flow), TECH_STACK, PRODUCT_SPEC row, ADR-089.
