## Context

The row of "Turn into" buttons (Text, H1, H2, H3, • List, 1. List, To-do, Quote, Code) above every page came from
the interim editor (E07-S10), when it was the only way to change a block's type with the mouse. It now repeats what
the slash menu (E07-S06), the block handle's "Turn into" list (E07-S04) and the Markdown shortcuts (E05-S01) do. It
takes the top of every page, sits above page covers, and isn't part of the Notion-like look in the spec. Owner asked
to remove it (2026-10-30).

## Acceptance criteria

- [x] The toolbar row is gone from every page; the page header (icon, cover, title) is the first thing in the page
- [x] Changing a block's type still works through the slash menu, the block handle's "Turn into" and Markdown
  shortcuts (each keeps its tests)
- [x] Nothing is lost: the toolbar only changed the block holding the caret, which the block menu also does
- [x] Before and after screenshots in `docs/screenshots/`
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-ui/src/shell/blocks.rs`: drop `toolbar_kinds` and the toolbar row; keep `Shell::turn_focused_into` (tests
  and future callers use it). Update the module doc.
- Test: an open page has no "Turn into" buttons (debug selectors on the page's first row).
- Docs: ARCHITECTURE line on the page, short ADR; screenshots light and dark.
