## Context

The spec's "Create or open a workspace (a local directory)" needs the app to remember workspaces. This is the
testable logic behind the welcome screen (E06-S09): a small settings file in the OS app-settings folder.

## Acceptance criteria

- [ ] Settings file (JSON) in the platform's app-config folder; unknown fields preserved
- [ ] Remembers the last opened workspace and a recent list (most recent first, max 10, no duplicates)
- [ ] Missing or moved workspaces are flagged, not silently dropped; "Remove from list" supported
- [ ] Corrupt or unreadable settings file → start fresh with a logged warning, never a crash
- [ ] Tests added; `just check` passes; docs updated if structure changed
