## Context

Model for typed text, composition (preedit) and commit.

## Acceptance criteria

- [x] Insert replaces selection
- [x] Preedit does not create undo steps until committed
- [x] Empty preedit never deletes selection
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Model:** new `PageCommand::ReplaceText { id, range, text }`, one commit, so typing over a selection or committing
  a composition is one undo step. The new text takes the formatting of the first replaced character (typing over a
  bold word stays bold, over link text keeps the link). Added to the invariants/undo proptest.
- **Editor (`leaf-editor/src/input.rs`):** a minimal one-block selection (`select`, `selection`, kept as a second
  anchor so it follows edits; any caret move drops it; E04-S06 grows it across blocks); `insert_text` replaces the
  selection or inserts at the caret; preedit (`set_preedit`, `commit_preedit`, `cancel_preedit`, `preedit()` for
  drawing) kept only in the editor, never written to the page, so it makes no undo steps or saves. An empty preedit
  ends the composition and leaves the selection alone.
- **Tests:** model replace tests (positions, one undo step, formatting, errors); editor tests for typing, replacing,
  selections following edits, compositions writing nothing, empty compositions, and a draft following remote edits.
  Docs: ADR 0017, BLOCK_MODEL command list, ARCHITECTURE.
