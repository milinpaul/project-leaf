## Context

Draw a callout as a rounded box with a tinted background and its tone's icon on the left, text wrapping beside it.
Clicking the icon opens a small picker of the five tones.

## Acceptance criteria

- [x] Each tone has its own background, icon and icon colour in light and dark mode; text stays readable (contrast checked)
- [x] Icons: Info ⓘ, Success ✓, Warning ⚠, Error ✕, Note 💡 (Lucide), fixed per tone
- [x] Clicking the icon opens a tone picker (the five tones, current one ticked); choosing one changes the tone (one undo step)
- [x] An unknown tone is drawn grey with the Note icon and can still be changed
- [x] Caret, selection, marks, IME and the formatting bar work inside callouts as in other text blocks
- [x] Screenshots in the PR, light and dark; previews shown to the owner before merge (approved 2026-10-31, with more space between callouts and the icon centred on the first line)
- [x] Tests added; `just check` passes; ARCHITECTURE updated

## Plan

- `theme::callout_hex`/`callout_colours`: background and icon colour per tone and appearance; a theme test checks
  text ≥ 7:1 and icon ≥ 4.5:1 on each background, and that the box stays soft against the page.
- `shell::callout`: the row (box, icon button, the usual rich-text body inside); the tone picker in the page's
  overlay (rows act on mouse-down, a click outside closes it, it closes itself if the callout goes); the format bar
  hides while it is open. `PageEditor::set_callout_tone` in `leaf-editor` (ignores non-callouts).
- Handle placement accounts for the box's padding. Lightbulb added to the bundled icons.
- Tests: editor (tone change, undo, non-callout ignored), theme contrast, window tests (box and icon, picker opens
  and changes the tone, unknown tone drawn and changeable, click outside closes). Screenshots light/dark.
