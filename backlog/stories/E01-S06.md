## Acceptance criteria

## Plan

- `Workspace` owns a Loro `UndoManager`, created after load so loaded history is not undoable.
  `undo()` / `redo()` return whether anything changed. Commits within the merge interval form one step; the
  default is 500 ms, as BLOCK_MODEL.md says (typing a title), and `set_undo_merge_interval` changes it (tests use 0).
- After every undo or redo, rebuild the `PageId ↔ TreeID` index: Loro re-creates nodes under new TreeIDs (ADR 0006).
- "Exact" is compared by `PageId`, order, and meta, ignoring TreeIDs (invariant 7 as reworded).
- Tests: undo and redo of every command type. Property test: random page commands (create, move, rename, icon,
  trash, restore, delete), recording the outline after each step; undo step by step must match each recorded
  outline back to the start, and redo all the way must reach the final one.
