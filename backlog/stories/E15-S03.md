## Context

When the clipboard holds only a web address, pasting offers a small menu: keep as link (default) or create a
web bookmark. The slash menu gets "Web bookmark", which asks for an address. A pasted address already becomes a
link (E17-S10); this adds the offer.

## Acceptance criteria

- [x] Pasting a bare URL makes it a link by default and offers "Create web bookmark"; any other key dismisses the offer
- [x] Choosing web bookmark replaces an empty block, or inserts a bookmark below, as one undo step
- [x] `/web bookmark` (also found by "bookmark") inserts a web bookmark after the owner types an address
- [x] Block menu offers "Turn into link" on a web bookmark and "Turn into web bookmark" on a block that is only a link
- [x] Web bookmarks are selected, copied, cut, moved and deleted as whole blocks, like images
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf-editor/web_bookmark.rs`: the offer after `paste_link` (anchor, length, address; stands while the caret is
  right after the untouched link; Enter in `press`, any other key closes it), `bookmark_offer_apply` (block that is
  only the link → bookmark + new line below; else link out, bookmark below; one undo step); the slash entry's address
  request (like Image) and `insert_web_bookmark` (`openable_url` + `check_web_address`); `link_swap` for the block menu.
- Block menu: `MenuEntry::ToLink` / `ToWebBookmark`; Turn into a bookmark skips blocks that would lose words.
- Found and fixed: a pasted divider, image or bookmark fragment into a line with text was lost; it goes below now.
- `leaf-ui/shell/web_bookmark.rs`: offer menu (page keeps the keyboard; Up/Down/Escape in page keys), address box
  (gpui-component Input, Escape and click-away cancel, hint for a bad address); Bookmark icon; slash and menu icons.
- Tests: editor (offer, slash, block menu, whole-block keys, clipboard), 5 window tests; Xvfb screenshots light/dark.
