## Context

When the clipboard holds only a web address, pasting offers a small menu: keep as link (default) or create a
bookmark. The slash menu gets "Bookmark", which asks for an address.

## Acceptance criteria

- [ ] Pasting a bare URL makes it a link by default and offers "Create bookmark"; any other key dismisses the offer
- [ ] Choosing bookmark replaces an empty block, or inserts a bookmark below, as one undo step
- [ ] `/bookmark` inserts a bookmark after the owner types an address
- [ ] Block menu offers "Turn into link" on a bookmark and "Turn into bookmark" on a block that is only a link
- [ ] Bookmarks are selected, copied, cut, moved and deleted as whole blocks, like images
- [ ] Tests added; `just check` passes; docs updated if structure changed
