## Context

When the clipboard holds only a web address, pasting offers a small menu: keep as link (default) or create a
web bookmark. The slash menu gets "Web bookmark", which asks for an address. A pasted address already becomes a
link (E17-S10); this adds the offer.

## Acceptance criteria

- [ ] Pasting a bare URL makes it a link by default and offers "Create web bookmark"; any other key dismisses the offer
- [ ] Choosing web bookmark replaces an empty block, or inserts a bookmark below, as one undo step
- [ ] `/web bookmark` (also found by "bookmark") inserts a web bookmark after the owner types an address
- [ ] Block menu offers "Turn into link" on a web bookmark and "Turn into web bookmark" on a block that is only a link
- [ ] Web bookmarks are selected, copied, cut, moved and deleted as whole blocks, like images
- [ ] Tests added; `just check` passes; docs updated if structure changed
