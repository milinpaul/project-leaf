## Context

Reported by the owner (2026-10-30). Near the bottom of the window, opening "Turn into" in a block's ⋮⋮ menu makes the
whole menu jump up. The main menu and the kinds list are one box pinned at the click and pushed back inside the
window, so when the tall kinds list opens, everything moves. Notion keeps the menu where it opened and fits the
submenu around it.

## Acceptance criteria

- [x] The main menu opens below the handle when it fits, otherwise above it, and doesn't move while it is open
- [x] The "Turn into" list opens beside the "Turn into" row, level with it when it fits; otherwise moved up only as far as needed to stay on screen; scrolls when taller than the window
- [x] At the right edge of the window the list opens on the menu's left instead
- [x] The placement rule is a plain function with unit tests (below/above, shifted, scrolled, flipped left); a window test opens the list near the bottom and checks the main menu didn't move
- [x] Screenshots near the bottom of a page in the PR
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Cause: `render_block_menu` drew the menu and the kinds list as one `h_flex` in one `anchored()` with
  `snap_to_window`; opening the tall list near the bottom snapped the whole box up.
- New `leaf-ui/src/shell/menu_place.rs` (pure geometry, unit tests): `menu_origin` (below the handle, else above,
  reusing the slash menu's `place`; kept inside the window sideways) and `list_bounds` (level with "Turn into",
  shifted up to fit, capped and scrolled when taller than the window, flipped left at the right edge).
- `shell/block_menu.rs`: both lists get a fixed 220 px width so their sizes are known before layout; the menu and
  the list are separate `anchored` elements at the computed spots; the open handle's top is remembered as well as
  its bottom; a click inside the list doesn't count as "outside" the menu.
- Window test: opened near the bottom, the menu sits above the handle, doesn't move when the list opens, the list
  fits in the window, and a kind can still be clicked. ADR 0041 amended.
