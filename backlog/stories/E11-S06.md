## Context

The `Cmd/Ctrl+K` search bar: a centred popup over the editor, like Notion.

## Acceptance criteria

- [x] `Cmd/Ctrl+K` (no text selected) and `Cmd/Ctrl+P` open it from anywhere in the window
- [x] Each result shows page icon, title, breadcrumb path and an excerpt with matched words highlighted
- [x] Choosing a result opens the page, scrolls to the matching block and briefly highlights it
- [x] Fully usable by keyboard; light and dark themes; "No results" state
- [x] Screenshot added to `docs/screenshots/`
- [x] Tests added; `just check` passes; the full CI matrix is checked on the `main` run after merge (the owner's rule of 2026-10-29 replaces the pre-merge matrix run)

## Plan

- **Popup** `leaf-ui/src/search.rs` (+ `search/view.rs`, `search/tests.rs`). It replaces the quick switcher's popup
  (`switcher.rs`), because Cmd/Ctrl+P now opens search; the switcher model stays inside `SearchBar`. It draws
  `leaf_editor::SearchBar` and forwards typing, keys and clicks.
- **Full text**:
  - A gpui timer fires at `next_deadline()`. `due()` then gives the request, which runs on the background
    executor: `leaf_search::Searcher::open(root)?.search(query)`.
  - The results are converted to `SearchHit` and passed to `deliver(id, …)`.
  - With no folder (tests) or no index yet, an empty result is delivered, so title matches still work.
- **Rows**:
  - page rows: icon, title (matches bold), breadcrumb;
  - excerpt rows: indented under their page, matched words bold on a soft tint;
  - states: "Recent pages", "Searching…", and "No results for “…”".
  The list scrolls with a `ScrollHandle` and keeps the highlight in view. Key hints sit at the foot.
- **Actions**:
  - `QuickSwitch` becomes `Search` (Cmd/Ctrl+P, menu "Search…").
  - New `SearchOrLink` (Cmd/Ctrl+K) asks `shortcut_action` with whether the page has a text selection. Link does
    nothing until the link popover (E07-S07).
- **Opening a result**: `Shell::open_at(Destination)` opens the page and, for a block, puts the caret at its start,
  scrolls it to the top and flashes it (a tint that fades over about 1.5 s).
- **Tests (GPUI)**:
  - Cmd/Ctrl+K and Cmd/Ctrl+P open search, and Cmd/Ctrl+K over selected text doesn't;
  - typing shows title matches;
  - full-text results from a real index in a temp folder, with Enter opening the page at the block;
  - a stale search never shows;
  - the "No results" state;
  - Escape closes.
- **Screenshots**: light and dark. **Docs**: an ADR and ARCHITECTURE. The full CI matrix is not run on the PR
  branch (owner's rule, 2026-10-29); the `main` run after merge is checked instead.
