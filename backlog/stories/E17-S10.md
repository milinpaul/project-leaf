## Context

The owner pastes a link and nothing happens (macOS). In tests, pasting a URL works everywhere: the editor puts the
text in mid-line, on an empty line and over a selection, and the paste key in a test window does too. So the
difference is what the Mac clipboard holds. GPUI's macOS clipboard reader (`gpui-pre-macos` `pasteboard.rs`)
reads only file paths, plain text and images; a link copied with only a web-link type (`public.url`, no plain
text) would read as nothing, and `Shell::on_paste` (`crates/leaf-ui/src/shell/page_keys.rs`) would do nothing.
Not yet confirmed: which app and copy command the owner used, and where they pasted.
