## Context

Pasting a URL puts it in as plain text, not as a link (the owner first said "nothing happens", then
clarified). Notion makes a pasted URL a link, and pasting a URL over selected text links that text. A preview
card for a pasted link is bookmarks (E15, Phase 1, needs the network) and is out of scope here.

## Acceptance criteria

- [x] Pasting a lone web address (`http://`, `https://`, `mailto:`, or starting with `www.`) puts it in as a link whose text is the address
- [x] Pasting one over selected text makes that text a link to it, keeping the text
- [x] Text that only looks like a file name (`notes.txt`), several words, or a paste into a code block stays plain text
- [x] One undo step; Cmd+K then edits or removes the link as usual
- [x] A failing test reproduces the bug before the fix
- [ ] Checked on macOS by the owner
- [ ] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf_editor::link::pasted_link(text)`: the href for a lone address with a scheme Leaf opens, or `www.`
  (stricter than `openable_url`, which also takes `example.com`, so `notes.txt` stays text).
- `PageEditor::paste_text`: before Markdown, a pasted link over a text selection runs `set_link`; elsewhere it is
  pasted as one span with the link mark. Code blocks keep plain text (checked first, as now).
- Tests in `clipboard/tests/pasted_links.rs`; PRODUCT_SPEC rule; ADR 0052 (links) amended.
