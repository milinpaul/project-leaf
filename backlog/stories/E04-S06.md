## Context

In-block and cross-block selection, Cmd/Ctrl+A escalation, block selection mode.

## Acceptance criteria

- [x] Shift+arrows extend across blocks
- [x] Cmd/Ctrl+A first selects block text, second selects all blocks
- [x] Typing over a cross-block selection deletes then inserts as one undo step
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- New `leaf-editor/src/selection.rs`: `Selection::Text { start, end }` (caret + tail anchor, may span blocks) and
  `Selection::Blocks` (block selection mode); `select`, `select_between`, `select_blocks`, `select_all`, `extend`,
  `extend_vertically`. Plain Left/Right collapse to the selection's edges.
- `delete_span`: deletes text across blocks with existing commands inside `PageDoc::as_one_step` (trim ends,
  delete blocks between, empty and merge away the blocks containing the last one, join).
- Typing, IME commit, Enter, Backspace, Delete and Tab over a cross-block selection: one undo step each. Block mode:
  Backspace/Delete delete, Tab nests; E04-S05's `SelectBlock` now enters it.
- Tests: `selection/tests.rs`, including a proptest that typing over any selection replaces exactly it, keeps
  invariants and undoes in one step.
