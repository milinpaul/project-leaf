## Context

Main window with resizable sidebar and page area.

## Acceptance criteria

- [x] Sidebar width and window size persisted
- [x] Sidebar can be hidden and shown (Cmd/Ctrl+\\); its width stays within 180-480 px
- [x] Settings file (JSON) in the OS app-config folder; unknown fields preserved; a corrupt file is set aside and Leaf starts fresh; a saved window that is off every screen is ignored
- [x] Menus with standard shortcuts per OS
- [x] Settings dialog (owner, 2026-10-29), opened from a cog at the bottom of the sidebar, the Settings… menu item
  and Cmd/Ctrl+,: sections **Appearance** (System / Light / Dark, saved), **Workspace** (name, folder path, Show in
  Finder/Explorer) and **About** (version, font licence); centred, closes with Esc or a click outside
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

**Scope (owner, 2026-10-29):** the first-launch open/create dialog moved to E06-S09 (the welcome screen covers
it); this story builds the app settings file that E06-S08 then extends with recent workspaces. Menus: the
standard set.

- **`leaf-store/src/settings.rs`** (tested, coverage-gated): `AppSettings` with the window frame (position, size,
  maximised), sidebar width and visibility, and every unknown field kept (`serde(flatten)`). `load` never fails:
  missing → defaults; unreadable/corrupt → logged, moved aside to `settings.json.bad`, defaults. `save` writes a
  temp file then renames. `settings_path` per OS (macOS Application Support, Windows %APPDATA%, Linux
  $XDG_CONFIG_HOME or ~/.config). `visible_on` drops a frame that is off every display. Width clamped 180-480.
- **`leaf-ui/src/settings.rs`:** a GPUI global holding the loaded settings and path; changes mark it dirty; saved
  on blur, quit and window close.
- **Layout:** `h_resizable` sidebar + page; resize updates the width; Toggle Sidebar hides/shows it.
- **Menus (`leaf-app`):** Leaf (About, Quit), File (New Page, Close Window), Edit (Undo, Redo, Cut, Copy, Paste,
  Select All, dispatched to the focused field), View (Toggle Sidebar), Window on macOS (Minimize, Zoom).
  Shortcuts use GPUI's `secondary` modifier (Cmd on macOS, Ctrl elsewhere).
- **Window:** opened at the saved frame if it is still on a screen, else centred; size and position recorded as
  they change.
- **Settings dialog** (added by the owner mid-story): gpui-component dialog with a section list on the left.
  Appearance is stored in the settings file and applied by `theme` (`LEAF_APPEARANCE` still wins, for screenshots).
  "About Leaf" opens it on About.
- **Tests:** settings round-trip, unknown fields, corrupt/missing files, paths per OS, clamping, off-screen
  frames; UI tests for toggling the sidebar and the menu list. Screenshots of the resized/hidden sidebar.
