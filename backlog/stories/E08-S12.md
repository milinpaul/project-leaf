## Context

Found by a security and code-smell review of the repo tooling (2026-10-31). `leaf-store/src/assets/kind.rs`
recognises SVG images. SVG is XML: a file can point at external files or URLs, expand entities, or describe a
huge or deeply nested picture. Rendering one must never read other files on disk, make a network request
(architecture rule 6), or exhaust memory.

## Acceptance criteria

- [ ] Find out how SVGs are decoded and rendered today (which crate, which options) and write it down in the Plan
- [ ] External references (`href` to files or URLs, `<image>`, external CSS/fonts) are never loaded
- [ ] Size limits: file size, rendered pixel size and nesting depth are capped; over the cap shows a placeholder
      with an error, and the original file is kept unchanged (rule 5)
- [ ] Tests with crafted SVGs: an external `href`, a `file://` image, a "billion laughs" entity file, a huge
      `viewBox`, deep nesting
- [ ] ADR if a renderer option or limit is chosen; `just check` passes
