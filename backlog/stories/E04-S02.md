## Context

Grapheme-aware cursor positions and horizontal movement.

## Acceptance criteria

- [x] Left/right by grapheme, word jumps, home/end
- [x] Correct with emoji, ZWJ sequences, Devanagari
- [x] Cursor survives remote/undo changes via Loro cursors
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Motions (leaf-editor, `caret/motion.rs`):** pure functions on a block's text with Unicode scalar positions (what
  the model uses): next/previous grapheme, word right/left (macOS style: skip spaces and punctuation, then to the end
  or start of the word), Home/End (start/end of the hard line, so code blocks with newlines work). Graphemes and words
  from `unicode-segmentation` (UAX #29; already in the lockfile through GPUI, pure Rust, wasm-ok).
- **Across blocks (`PageEditor::move_caret`):** Left at a block's start goes to the end of the previous text block in
  reading order; Right at the end goes to the start of the next. Blocks without text (divider, image) are skipped.
  Home/End stay in the block. Up/Down are E04-S03.
- **Surviving changes:** `leaf-model` gets `Anchor` (a Loro cursor plus the caret as a fallback) with
  `PageDoc::anchor` and `PageDoc::resolve`, and `PageDoc::import_changes` to merge another copy's changes (only tests
  use it in Phase 0). `PageEditor` keeps the caret as an anchor: `set_caret`, `caret()`, `move_caret`. If undo
  re-created the block (new Loro container) the stored position is clamped; if the block is gone, the caret goes to
  the nearest block above it in the last drawn order. Resolved positions are snapped to a grapheme boundary.
- **Tests:** unit tests per motion with emoji, ZWJ families, flags, combining marks, Devanagari conjuncts; proptest
  that every motion lands on a grapheme boundary and Left/Right round-trip; two-peer tests for remote insert/delete
  before the caret; undo tests. Docs: BLOCK_MODEL, ARCHITECTURE, ADR 0015 (caret anchors).
- **Risk:** Devanagari conjuncts need UAX #29 rule GB9c (Unicode 15.1); check the crate version supports it.
