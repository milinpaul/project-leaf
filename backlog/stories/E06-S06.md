## Context

A Trash page, like Notion's: open it from a "Trash" row at the foot of the sidebar (above Settings). It lists pages
moved to the trash (newest first, with when they were trashed and where they lived), so they can be put back or
removed for good. The model already has `Workspace::trash`, `RestorePage` and `DeletePagePermanently`; storage
does not yet drop the documents of deleted pages, and the search index must forget them.

## Acceptance criteria

- [ ] Trash row in the sidebar opens the Trash view; it shows each trashed page's title, icon, when it was trashed
      and its old parent, with a filter box for long lists
- [ ] Restore puts the page (and everything inside it) back where it was, or at the end of the top level if its
      parent is still in the trash
- [ ] Delete forever removes one page and everything inside it, after a confirmation dialog
- [ ] Empty trash deletes every trashed page, after a confirmation dialog naming how many pages go
- [ ] Deleted pages' documents are removed from `workspace.sqlite` and from the search index; nothing else is touched
- [ ] Opening a trashed page (from the Trash view; the switcher hides them and search isn't built yet) shows a "This page is in the trash" banner with Restore and Delete forever
- [ ] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Store**: `Store::delete(DocKey)` removes a document's snapshot and updates in one transaction.
- **Editor (`leaf-editor`, `workspace_editor/trash.rs`)**: `trash_items()` (title, icon, trashed time, where it
  lived as a breadcrumb), `restore`, `delete_forever` and `empty_trash` (both return deleted page IDs and forget
  those pages' blocks, expanded and recent state; the open page closes if deleted), `selected_in_trash()`.
  `TrashList` filters items with the switcher's fuzzy matcher; `trashed_ago(now, at)` gives "3 min ago".
- **Store wiring (`leaf-ui` storage)**: after a permanent delete, flush the workspace first, then delete the page
  documents and forget them in autosave (a crash leaves orphans, never a live page without its blocks); poke search.
- **UI**: a "Trash" row above Settings opens a Trash dialog: filter field, rows (icon, title, where it lived, when),
  Restore and Delete forever on each row, Empty trash at the foot; confirmations via an alert dialog with a red
  button. Clicking a row opens the page with a banner (Restore / Delete forever).
- **Tests**: store delete; editor trash list, restore (incl. parent in trash), delete, empty, selection; GPUI: trash
  then restore from the dialog, delete forever with confirm, empty trash, banner.
