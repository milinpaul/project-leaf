## Context

Copying and pasting action items inside Leaf keeps everything; copying out to other apps writes readable
Markdown, and pasting that back makes action items again.

## Acceptance criteria

- [x] Leaf's own clipboard fragment carries done, date, time and priority; copy then paste on an empty line gives back the same item
- [x] Markdown out: a task list line with the date and priority readable in plain text (format decided and recorded in ADR 0032), e.g. `- [ ] Send invoice (due 2026-10-31 14:00, high)`
- [x] Pasting that Markdown back makes an action item; plain `- [ ]` lines still become to-dos
- [x] BLOCK_MODEL.md "Markdown mapping" updated
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- Leaf's fragment already carries every field (E19-S01); add a Markdown round-trip test through a real paste.
- New `leaf-editor/src/clipboard/markdown/task.rs`: write an action item as `- [ ] text (due YYYY-MM-DD HH:MM, high)`,
  `(action item)` when it has no fields; read a to-do line's final group only when every part is a known one
  (any order and case). A to-do whose text would read as such a group gets its bracket escaped (`\(`).
- Hook it into `markdown.rs` (reading to-do lines; writing; list-item spacing). Unit tests for read/write/escape,
  an inline snapshot of the copied Markdown, and pasting it back.
- Docs: ADR 0032 update (format and alternatives), BLOCK_MODEL "Markdown mapping", ADR 0068, PRODUCT_SPEC row.
