## Context

Ways to make a callout: the slash menu, a Markdown shortcut, and copy/paste as Markdown using GitHub's alert syntax.

## Acceptance criteria

- [x] Slash menu: `/callout` (Info), plus `/info`, `/success`, `/warning`, `/error`, `/note` for each tone
- [x] Typing `> [!NOTE] `, `> [!TIP] `, `> [!WARNING] ` or `> [!CAUTION] ` at the start of a block turns it into an Info, Success, Warning or Error callout (`> [!IMPORTANT] ` → Note); plain `> ` still makes a quote
- [x] Copy as Markdown writes callouts as GitHub alerts (Info→NOTE, Success→TIP, Warning→WARNING, Error→CAUTION, Note→IMPORTANT); pasting such Markdown makes callouts back, keeping their text and marks
- [x] PRODUCT_SPEC "Markdown shortcuts" updated
- [x] Tests added; `just check` passes

## Plan

- `clipboard::markdown::alert_tone` maps GitHub alert names to tones (inverse of `alert_name`, used by copy since
  E21-S01). Paste: a `> [!X]` line opens a callout (text after the marker is its first line); the `>` lines that
  follow at the same indentation are its lines, joined with line breaks; a blank or other line ends it.
- Shortcut: `> [!X] ` typed at the start of a block, or `[!X] ` in a quote (typing `> ` already made it one), makes
  a callout; its own undo step as for every shortcut. Unknown names stay text.
- Slash menu: `Callout` (info) and `Callout: Success/Warning/Error/Note`, with tone keywords. Named "Callout: …" so
  `nl` still finds Numbered list first. Each shows its tone's icon.
- Tests: shortcut (every name, case, plain quote, unknown name, whole alert at once, undo), slash (each query),
  paste (lines, marks, two alerts, plain quote after), copy→paste round trip for every tone. PRODUCT_SPEC and
  BLOCK_MODEL Markdown mapping.
