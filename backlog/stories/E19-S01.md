## Context

A new block kind for action items in `leaf-model`: rich text like a to-do, plus done, a due date, an optional due
time and a priority. Commands set each of them with undo, and two peers changing different fields converge.
Write the ADR for the shape: one kind with props (as to-do keeps `checked`), the date and time format, and how
it stays apart from the to-do kind.

## Acceptance criteria

- [ ] `BlockKind::Task { done, due, time, priority }` with `Priority` High / Medium / Low and none; date as `YYYY-MM-DD`, time as `HH:MM` (24 h), both optional, time only with a date; documented in BLOCK_MODEL.md
- [ ] Commands: set done, set due date (and clear), set due time (and clear), set priority; each one undo step; invalid dates and times are refused
- [ ] Undo/redo round-trips and two-peer convergence (proptest)
- [ ] A task from a newer version with props Leaf doesn't know keeps them when saved
- [ ] Saved and reopened through `leaf-store` unchanged; ADR written and added to the index
- [ ] Tests added; `just check` passes; docs updated if structure changed
