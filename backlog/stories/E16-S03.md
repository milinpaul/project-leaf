## Context

Draw the table view model in `leaf-ui`: a bordered grid with editable cells, caret and selection in cells, and
small controls to add a row or column. A wide table scrolls sideways inside the page rather than widening it.

## Acceptance criteria

- [x] Table draws with the theme's borders and a bold header row; cells show caret, selection and marks
- [x] Hover controls add a row at the bottom and a column at the right; a row/column handle menu inserts, deletes and moves
- [x] Wide tables scroll horizontally inside the block; the page doesn't scroll sideways
- [x] Verified with screenshots in light and dark
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- **Editor** (`leaf_editor::table`): `PageEditor::edit_table(table, TableEdit)` for the UI's controls: insert,
  delete or move a row or column, toggle the header row. One undo step each; the caret goes into the new cell, or
  stays in the same place when its row or column moved or went.
- **UI** (new `leaf-ui/src/shell/table_row.rs`): the table's row draws the whole grid; the cell rows that follow it in
  the view draw nothing (zero height), so the list stays in step with the editor's rows. Cells use the existing
  rich-text renderer, so the caret, selection, marks, clicks, drags and input methods work unchanged. Header row
  bold on a tint; borders from the theme; whole cells tinted when a cell selection covers them.
- **Wide tables:** columns have a fixed width (160 px); the grid sits in a horizontally scrolling box, so the page
  never scrolls sideways.
- **Controls:** on hover, a "+" bar under the table adds a row and one at its right adds a column. A slim handle
  before each row and above each column opens a menu: insert above/below (left/right), move up/down (left/right),
  delete, and on the first row "Header row".
- **Tests:** editor tests for each `TableEdit` (caret, one undo step, refusals); window tests: the grid draws every
  cell, a click puts the caret in a cell, typing goes there, the "+" controls add a row and a column, the box scrolls
  instead of the page. Screenshots of a real table in light and dark (a throwaway workspace built with the table
  commands, since `/table` is E16-S04).
- **Docs:** ARCHITECTURE.md table paragraph; ADR only if a decision comes up beyond ADR 0063.
