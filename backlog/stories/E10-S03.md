## Context

The editing rules for a link inside text (ADR 0071): it behaves as one character, and the view model tells the UI
what to draw: the target's current title and icon, or that it is in the trash or deleted.

## Acceptance criteria

- [ ] Arrow keys step over a link in one press; Shift+arrows select it whole; Backspace/Delete remove it whole; a selection can't end inside it
- [ ] Typing next to a link never becomes part of it; Enter before or after it splits cleanly
- [ ] View model: each link as a run with the target's title and icon, and a state (live, in trash, deleted); renaming the target changes the view without touching the page
- [ ] Clipboard: rich copy/paste keeps links; plain text writes the title; Markdown writes `[[Title]]`; pasting Markdown `[[Title]]` makes a link when exactly one page has that title
- [ ] Search indexes a link as nothing (titles are found by title search); decided in the plan if that changes
- [ ] Tests for every rule (PRODUCT_SPEC.md Editor behaviour gains a Page links row); `just check` passes
