## Context

Make the sidebar feel premium, like Notion's. The page tree's right-click menu gets icons, and the "New page"
button gives way to a workspace header row and small icon buttons: a compose button at the top and a "+" beside the
Pages heading. Owner's request after E06-S03.

## Acceptance criteria

- [x] Context menu items have icons: plus (Add page inside), pencil (Rename), trash (Move to Trash)
- [x] Sidebar header: workspace badge (initial on a soft accent square) and name, with a compose (new page) icon button
- [x] "Pages" section heading with a "+" icon button that adds a top-level page; tooltips on icon buttons
- [x] Rows show a page icon when the page has no emoji, and a "+" on hover that adds a page inside
- [x] Extra icons are bundled from Lucide (already licensed) without embedding the whole icon set
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf_ui::assets()` serves a few extra Lucide icons (trash, square-pen, pencil-line, file-text) through
  `gpui_kit_assets::icon_assets!`, falling back to the component icons; test that they load.
- Context menu items get `.icon(...)`.
- Sidebar header (`shell.rs`): workspace badge + name (folder name without `.leaf`), compose icon button with tooltip.
- "Pages" heading row with a "+" that fades in on hover; rows get a file icon when they have no emoji and a hover
  "+" (add page inside) at the right, using group hover.
- GPUI tests: compose and "+" buttons create pages; row "+" adds a child. Screenshots light/dark; ADR not needed
  (no structural change), ARCHITECTURE line updated.
