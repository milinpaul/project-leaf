## Context

Show which pages link to the open page (PRODUCT_SPEC.md Phase 1; ADR-071 answer 3): a "3 backlinks" line under
the title, hidden when there are none, opening a list.

## Acceptance criteria

- [x] Under the page title: "N backlinks" when N > 0; nothing otherwise
- [x] Clicking it opens a list: each linking page with its icon, title and the sentence with the link, the link highlighted
- [x] Choosing an entry opens that page and scrolls to the block, as search results do
- [x] The count and list update after the linking page is saved, without reopening
- [x] Window tests; screenshots light and dark; `just check` passes

## Plan

- leaf-editor `workspace_editor/backlinks.rs`: `BacklinkSource` (what the index found, plain data),
  `WorkspaceEditor::backlinks` (rows with current titles and icons, pages in the trash or gone left out),
  `backlinks_label` ("1 backlink", "3 backlinks", none for 0).
- leaf-ui `shell/backlinks.rs`: the line under the title in `render_page_header`, the list in place, a click via
  `open_at`; the index asked on page open, a moment later, and at most once a second after.
- Tests: view model; window tests (no line without backlinks, list opens, entry opens page at block, a new page
  starts closed). Screenshots from the demo workspace.
