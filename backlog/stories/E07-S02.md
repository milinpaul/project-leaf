## Context

Custom GPUI element painting text runs with marks, caret and selection; implements LineLayout.

## Acceptance criteria

- [x] Marks rendered (bold, italic, strike, code, link)
- [x] Caret blink and selection highlight across blocks
- [x] LineLayout implementation matches painted text
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

Owner's choice: two steps. S02 draws every block except the one being typed in with the new view (app stays
editable); S03 moves typing into it.
- `leaf-ui/src/shell/rich_text.rs`: `StyledText` per block from its runs (bold, italic, strike, inline code, link),
  block look (heading, code, done to-do), selection as run background, overlay recording the layout and painting the
  blinking caret. Clicking a row focuses its input at the clicked character.
- `rich_text/pieces.rs` (pure): per-row highlights from the editor's selection; runs split at selection edges.
- `rich_text/painted_layout.rs`: `PaintedLayout` implements `LineLayout` from painted layouts.
- Tests: pieces/highlights unit tests; window tests: every offset round-trips through the painted layout of a
  wrapped paragraph, Up/Down move between painted lines, off-screen blocks, caret blink. Headless screenshots.
