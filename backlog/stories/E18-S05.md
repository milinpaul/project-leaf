## Context

Starred pages appear in a "Favourites" section at the top of the sidebar, above the page tree, so they are one click
away. Hidden while there are none.

## Acceptance criteria

- [x] A "Favourites" section above the page tree lists starred pages in order, with icons and titles, hidden when empty
- [x] Clicking one opens it; the open page is highlighted there as in the tree
- [x] Right-click offers Remove from Favourites plus the usual page actions
- [x] Follows renames, icon changes, trash and restore at once
- [x] Screenshots in the PR, light and dark
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

- `leaf_ui::shell::favourites`: heading and rows from `WorkspaceEditor::favourites` (already in the editor,
  E18-S02), between the search field and "Pages"; same row height and icon column as the tree; hidden when empty.
- Right-click: `page_menu` with a new `MenuPlace::Favourites` (same entries as a tree row). Rename edits the
  row that was right-clicked: `Rename` remembers whether it is in Favourites.
- Tests: editor (Favourites menu = sidebar menu); window tests for showing/hiding, order, open + highlight,
  following rename/icon/trash/restore, Remove from Favourites and renaming in the Favourites row.
- ARCHITECTURE line; no ADR (the model decision is ADR-060).
