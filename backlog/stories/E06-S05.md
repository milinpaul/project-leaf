## Context

Editable title and emoji icon picker.

## Acceptance criteria

- [x] Title edits sync to sidebar live
- [x] Title reads as the page's heading 1: inline, no box or border, large bold text, grey "Untitled" placeholder (Notion-like; quick version shipped in E06-S07)
- [x] Enter in title moves cursor to first block
- [x] Emoji picker with search
- [x] Tests added; `just check` passes; docs updated if structure changed

## Plan

Already shipped by E06-S07/E06-S03: live sidebar sync, the inline heading style, Enter into the first block. This
story adds the page icon:
- **Data**: the `emojis` crate (MIT/Apache + Unicode-3.0, no required deps, wasm-ok) for the emoji list, names,
  groups and shortcodes; only emoji up to Unicode 13 so every OS font can draw them.
- **Editor (`leaf-editor/src/emoji_picker.rs`)**: `EmojiPicker` with sections by group, search by name and shortcode
  (each word must start a word), a random pick; `WorkspaceEditor::set_icon` (no change when the same).
- **UI**: above the title, the icon (large, click to change) or an "Add icon" button that shows on hover; a popover
  under it with a search field, Random and Remove, and a grid that draws only visible rows. Enter picks the first
  match, Esc closes.
- **Tests**: picker search/ranking/sections, set_icon undo-free no-op, GPUI: add icon via picker, remove it,
  sidebar shows it. ADR for the new dependency.
