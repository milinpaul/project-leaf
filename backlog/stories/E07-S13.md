## Context

Formatting today is keyboard-only (Cmd/Ctrl+B, I, E, Shift+S, K). The owner wants a small floating bar, as in Notion,
that appears above selected text with: a "Turn into" dropdown, Bold, Italic, Strikethrough, Inline code and Link.
It shows for any text selection, inside one block or across blocks (owner's choices, 2026-10-30).

The toggles (`PageEditor::toggle_mark`), the link popover (ADR 0052), `active_marks` and the block menu's Turn into
list (`turn_into_kinds`) already exist; this story puts them in reach of the mouse.

## Acceptance criteria

- [x] Selecting text (mouse or keyboard) shows a bar just above the start of the selection, below it when there is no room above; it never covers the selected text
- [x] Buttons: Turn into ▾, Bold, Italic, Strikethrough, Inline code, Link; each has a tooltip with its shortcut
- [x] A mark button is shown as active when the whole selection has that mark; clicking it toggles the mark exactly like its shortcut (one undo step), and the selection stays
- [x] Link opens the existing link popover for the selection
- [x] Turn into lists the same kinds as the block menu, marks the current kind, and changes every block the selection touches (one undo step)
- [x] Across several blocks, marks apply to all selected text; code blocks are skipped as with the shortcuts; a selection only inside a code block shows no mark buttons
- [x] The bar hides when the selection collapses, on typing, on Escape, while dragging a selection, and when the link popover or another menu opens; it does not take keyboard focus
- [x] Which buttons show and which are active comes from `leaf-editor` (a small view model), tested without the UI
- [x] Screenshots in the PR, light and dark
- [x] Tests added; `just check` passes; ADR, ARCHITECTURE and PRODUCT_SPEC "Editor behaviour" updated

## Plan

- `leaf-editor/format_bar.rs`: `PageEditor::format_bar()` → `FormatBar { start, end, kinds, kind_label, marks }`,
  `None` without selected text; no marks for code-only selections; no Turn into when a block can't change kind.
- `leaf-ui/shell/format_bar.rs`: placed from last frame's painted layout above the start (below the end if no
  room); buttons call `toggle_mark` / `open_link_popover` / `turn_focused_into`; Turn into list drawn in the same
  overlay (a popup menu would take the keyboard). Hidden while dragging, unfocused, or another popover/menu is open.
- Icons Bold, Italic, Strikethrough, Code added to the bundled set.
- Tests: editor model (6), window tests (5); screenshots light/dark. ADR 0066, ARCHITECTURE, PRODUCT_SPEC row.
