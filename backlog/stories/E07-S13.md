## Context

In the ⋮⋮ block menu (`shell/block_menu.rs`, `leaf_editor::block_menu`, ADR 0041), hovering "Turn into" doesn't
open the list of kinds; it needs a click. Once open, moving the mouse towards it closes it, so a kind such as
Heading 2 can only be chosen with the keyboard. It should behave like a normal submenu.

## Acceptance criteria

- [ ] Hovering "Turn into" opens the kinds list after a short delay; clicking also opens it
- [ ] Moving the mouse from "Turn into" into the list (including diagonally across other rows) keeps it open
- [ ] Clicking a kind turns the block into it and closes the menu; hovering another row of the main menu closes the list
- [ ] Keyboard behaviour unchanged (existing tests still pass)
- [ ] Tests added; `just check` passes; docs updated if structure changed
