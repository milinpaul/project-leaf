## Context

Point a link at one block of a page (`(PageId, BlockId)`, reserved in BLOCK_MODEL.md; ADR-071 answer 4).
Later: the owner chose to leave it out of the first round (2026-10-31).

## Acceptance criteria

- [x] Plan the mark value (page plus block), the way to pick a block ("Copy link to block" in the ⋮⋮ menu, paste), and what shows when the block is gone
- [x] Clicking opens the page and scrolls to the block
- [x] Tests added; `just check` passes

## Plan

Owner's answers (2026-11-01): label "🏨 Page › block words…"; made with "Copy link to block" in the ⋮⋮ menu and
pasted; a deleted block shows "Page › deleted block" greyed and opens the page at the top; a click scrolls to the
block, puts the caret there and flashes it.

- **Model (`leaf-model`):** a block link is a page link (the placeholder and its `page` mark, unchanged) with a
  second `block` mark holding the `BlockId`. Older versions keep both marks and open the page. New command
  `PageCommand::InsertBlockLink`; `Marks.block`; the block mark is copied placeholder by placeholder like the page
  mark; invariant 10 grows "the block mark only sits on a page link", with the merge repair; re-pointing a link drops
  its block. Backlinks need no change (it is still a link to the page).
- **Editor (`leaf-editor`):** `LinkTarget` gains the block's words or "deleted block" (new `LinkState::BlockGone`,
  greyed but opens); `DrawnLink.block`; `WorkspaceEditor::link_target(page, block)` reads the words from the target
  page if it is loaded; "Copy link to block" in the block menu builds a fragment with one block link; fragment paste
  and the Markdown/plain text names carry the block.
- **UI (`leaf-ui`):** opening a page also loads the pages its block links point at (so labels read live words);
  clicking a block link goes through `Shell::open_at` (scroll, caret, flash); the menu entry writes the clipboard.
- **Tests:** model commands, copy/split/merge/duplicate keep the block, repair, undo; editor label states, the menu
  entry, copy and paste round trip; UI click opens and flashes the block, deleted block opens the top.
- **Docs:** BLOCK_MODEL.md (mark table, invariant 10), ARCHITECTURE.md, ADR-XXX-E10-S08.
- **Risk:** a link to a page that isn't loaded yet shows only the page until loaded; loading is a few pages per open.
