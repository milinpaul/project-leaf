## Context

Found by the owner (2026-10-31):

- Pressing Enter with the caret at the very start of a heading (H1–H3) or quote turns the text into plain
  text. Enter splits the block at the caret: the empty half before the caret keeps the heading's kind, and the
  text moves into a new paragraph below (`SplitBlock` makes the new half a paragraph for anything but lists).
- In a quote, Enter always ends the quote, so a quote can't continue on another line. Lists (Enter, then Enter
  on the empty item to stop) and callouts (line breaks, Enter on an empty last line to leave) work as wanted.

Owner's decision (2026-10-31): a quote works like a callout, holding several lines under one bar.

## Acceptance criteria

- [x] Enter at the start of a paragraph or heading with text adds an empty paragraph above; the block keeps its
      kind and the caret stays at its start (one undo step). Lists, to-dos and action items still continue in
      their own kind
- [x] Enter in a quote adds a line break inside it, including at its start; Enter on an empty last line (or in
      an empty quote) removes that line and adds a paragraph below; `Cmd/Ctrl+Enter` leaves from anywhere
- [x] A quote's bar runs down all its lines
- [x] `PRODUCT_SPEC.md` "Editor behaviour" rows updated; one test per row; decision record for the quote change
- [ ] `just check` passes; PR CI green

## Plan

- `leaf-editor/src/page_editor.rs` `enter_in`: at position 0 of a non-list block with text, insert an empty
  paragraph before it (new `insert_before`) instead of splitting.
- `leaf-editor/src/keys.rs`: treat `Quote` like `Callout` in `enter_key` and `enter_over` (line break, leave on an
  empty last line, `Cmd/Ctrl+Enter` leaves).
- `leaf-ui/src/shell/block_row.rs`: the quote bar stretches to the row's height instead of a fixed 24 px.
- Tests: `keys/tests/block_start_and_quotes.rs` (7 tests, 5 failing before the fix); the old mid-quote split test
  and the long-document acceptance test follow the new rule; a window test for a two-line quote's bar.
- Markdown copy already writes each quote line as `> line`, so nothing changes there.
